# セキュリティ人生シミュレーション

セキュリティに詳しくない一般の人が、人生シミュレーションを遊ぶ中で、日常のリスクと影響・対策を自然に学ぶゲームの開発リポジトリです。

親しみやすい2Dドット絵の世界を探索し、自由行動とイベントでの選択を通じて人生を送ります。学校、交友、仕事、恋愛、結婚、介護などの生活を主軸に、子どもから高齢までの全年代を含むゲームの完成を目指します。

現在は企画方針と機能の共通仕様、未採用の案を文書化している段階です。素材用ディレクトリも用意していますが、ゲーム本体と素材はまだありません。技術スタックやデプロイ方式は未決定です。

## ドキュメント

| 文書 | 役割 |
| --- | --- |
| [全体企画書](docs/product.md) | 目的、対象ユーザー、体験の核、ゲーム概要、全年代のイメージ |

| [概念設計](docs/architecture.md) | 概念上の責務の分離と、今後の技術選定で決める事項 |
| [イベント候補と詳細の管理](docs/events/README.md) | 個別イベントの管理方針。現在は採用未決定・年代未分類のSEC-001〜015を保持 |

| [判断の記録](docs/decisions/README.md) | 重要な決定と理由 |
| [素材置き場](assets/README.md) | 画像・音声・フォントなどの配置先と権利確認のルール |

合意済みの方針と未決定事項は、各文書で区別しています。イベント候補や演出案を記録したことは採用の決定を意味しません。数値仕様、細かい分岐、人生の進行速度、年代別の詳細、マップ接続、アイテムを欲しくなるきっかけや入手への導線、技術スタックは未決定です。

タスク、優先度、進捗は GitHub Issues / Projects、合意済みの方針と仕様は docs/ で管理します。
