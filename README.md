# セキュリティ人生シミュレーション

一般の方向けに、人生シミュレーションを楽しみながら日常の情報セキュリティリスクと対処を学べるゲームを開発するための公開リポジトリです。

現在は公開環境の準備段階で、index.html は仮の案内ページです。ゲームの実装は未着手です。内部の設計資料や作業ログは含めていません。

## ロリポップ！デプロイナウ

[ロリポップ！デプロイナウ](https://lolipop.jp/deploy-now/) にGitHub経由で接続できる構成です。

GitHub接続の初回設定で、このリポジトリを選び、main ブランチ、フレームワーク「静的サイト」を指定してください。ルートの index.html が配信されます。接続後は main へのpushで自動デプロイされます。

公式ドキュメント: https://deploy.lolipop.jp/docs/integrations/github

このGitHubリポジトリの作成だけではデプロイナウ側のプロジェクトは作成されず、公開URLも発行されません。
