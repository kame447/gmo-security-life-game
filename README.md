# セキュリティ人生シミュレーション

一般の人が人生シミュレーションを楽しみながら、日常のセキュリティリスクとその影響・対処方法を学ぶゲーム。

日本の準都会を舞台に、分割型2Dドット絵の町と建物内部を歩いて探索し、生活やイベントでの選択を通じて幼少期から老後までの人生を送る。
