# 開発ロードマップ

幼少期から老後までの全年代を含む人生シミュレーションを、数か月の開発期間で完成させる。

## 開発の進め方

最初に、マップ探索、自由行動、イベント選択、状態変化をつなぐ基本体験を具体化して検証する。

次に、各年代の生活内容とイベントを加え、過去の選択が後の人生に影響する仕組みを全段階へ展開する。

最後に、ゲーム全体の遊びやすさ、日常とセキュリティイベントの配分、リスクと対処方法の伝わり方を検証する。

## タスク管理

具体的な作業と進捗は GitHub Issues / Projects、機能仕様は [機能仕様](features/README.md) で管理する。
