# 0006: プロトタイプのスマートフォン基盤

記録日：2026-11-13

状態：採用（プロトタイプの構成。操作と内容は提案／要検証）

関連：[Issue #22](https://github.com/kame447/gmo-security-life-game/issues/22)、[スマートフォン基盤](../features/phone.md)

## 背景

生活行動と将来のデジタル上のイベントには共通の画面が必要だが、スマートフォンの入手条件や個別の出来事は未決定。探索・会話・外見変更を壊さず、実サービスへ接続せずに基盤を検証したい。

## 決定

- アプリ、画面、通知、表示データを画面遷移と分け、画面間はアプリ内の ID で参照する。メッセージと擬似 Web は仮データを用いる。
- 初期所持を設定可能な既定値とし、進行側から所持状態を変更する API を設ける。入手条件は今回実装しない。
- 既存の v1 セーブへ任意の `phone` 欄を加え、所持状態のみを保存する。画面を開いた状態や履歴は復元しない。不正な欄は既定値に戻し、他の正常な欄から切り離す。
- UI モードを既存の入力振り分けに追加し、探索からのみ起動する。画面中は探索入力を遮断し、閉じると入力を解除する。

## 今後の判断

所持条件の詳細、通知の履歴、セーブスロット、各アプリの内容とイベント接続は未決定。既存の SEC 候補の採用を前提にしない。
