# 0006: ゲーム内スマートフォンの状態と画面

記録日：2026-11-13

状態：状態と画面分離の試作。見た目・操作の細部は提案／要検証。

関連：[Issue #22](https://github.com/kame447/gmo-security-life-game/issues/22)、[スマートフォン](../features/phone.md)

## 背景

スマートフォンは日常行動と将来のデジタルイベントの入口だが、入手条件と個々の出来事は未決定。従来の簡素な画面はゲームとして不十分との利用者の指摘があり、端末として認識できる UI を試作し直す。

## 方針

- 所持と画面遷移を DOM から分け、初期値を切り替え可能にする。進行側は所持状態とローカルの表示データを変更できる。
- v1 セーブに任意の `phone` 欄を設けて所持だけを保存し、画面履歴は復元しない。旧セーブ・不正欄は初期値へ戻す。
- 共通モーダルの登録口を通し、探索・会話・外見や他パネルと入力が競合しないようにする。
- アプリと通知の参照はゲーム内 ID とし、実サイトや認証サービスへ接続しない。
- 今回の端末フレーム・配色・アイコン・アプリ配置はレビュー用の試作とし、画像と実操作を利用者が確認してから採否を決める。

## 未決定

物語上の入手時期、アプリの正式な内容、通知の履歴、実際の生活サービスやイベントの接続は別途設計する。
