# 0006: ゲーム内スマートフォンの状態と画面

状態: 候補／要検証。[Issue #22](https://github.com/kame447/gmo-security-life-game/issues/22) の画面は利用者レビュー待ちです。

スマホの所持、ローカル画面遷移、通信残量の計算、表示を分けます。現在のサンプル画面はゲーム内 ID で遷移し、外部の通信や認証を行いません。通信残量は単調時計の差分と位置・開閉・所持状態から算出し、既存 v1 セーブへ任意欄として保存します。

暫定の容量・速度、補充や枯渇後の扱い、画面デザイン、登場するサービスの内容は最終決定ではありません。pause・非表示・ゲーム終了中の扱いも設定で分離し、比較用の既定値では減らしません。詳細は[スマートフォン](../features/phone.md)と[通信容量](../features/phone-data-budget.md)に記載します。
