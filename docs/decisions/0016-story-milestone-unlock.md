# 0016: ステージ全体の制限時間をやめ、必須イベントの解放と自分で選ぶ節目で進める

状態：Issue #85 のレビュー（kame447、2026-11-25）を受けた利用者（misanga1225）の決定（2026-11-27）。[0015](0015-story-time-limited-stages.md) のうち、ステージの制限時間と時間切れによる自動移行を置き換える。序章・必須イベントの考え方は 0015 から維持する。

## 背景

0015 の試作（PR #77）では、中学・高校とも180秒の制限時間があり、時間切れになると未経験の必須イベントを場所に関係なくその場で消化してから卒業していた。遊んだ結果、町を探索した後に学校生活が会話だけでまとめて終わってしまい、途中を過ごした感じが残りにくいという指摘があった（Issue #85、#18）。

イベント数は増やさず、短い時間で最後まで遊べる形にしたいという意見もあった（i2rin、haRusuZu41）。

## 方針

- ステージ全体の制限時間をなくす。時間切れによる自動移行と、まとめての消化もなくす。
- 各ステージの必須イベントは定義順に一つずつ解放する。前の必須イベントを経験すると次が解放される。必須イベントの合間は自由に探索できる。
- 必須イベントのきっかけは「場所に入ったとき」か「解放されてから探索中に一定時間たったとき（電話・チャットなど、その場で起きる出来事）」とする。個別の出来事を時間で起こすことは残す。
- 必須イベントをすべて経験すると節目が解放される。プレイヤーが自室のベッドで次へ進むと選んだときだけ次のステージへ移る。解放後も探索できる（[0005](0005-task-based-life-progression.md) の「プレイヤー自身が次年代へ移る操作を選ぶ」に戻す）。
- 前の選択によって、後のステージで起きる必須イベントを変えられる。日常の選択に加え、セキュリティで間違えた選択は後の被害の出来事として返る（例：中学でパスワードを使い回し、高校の流出通知を放っておくと、社会人で会社のアカウントに不正ログインされる）。
- 学校・会社からの知らせはスマホの受信トレイに届け、会話欄には出さない（#73 のレビュー）。
- ステージの区切りはガントチャート（`docs/Gantt_chart.png`）に合わせ、中学生 → 高校生 → 大学生 → 社会人 → 中年・老後の5つとし、最後に人生を振り返って終える。重点の高校・大学・社会人に出来事を多く置く（2026-11-28、利用者の指示）。
- 専用のマップがない場所（高校・大学・会社）は既存の場所で仮置きし、置き換えは別の作業とする。
