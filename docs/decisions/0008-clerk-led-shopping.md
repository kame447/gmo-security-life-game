# 0008: 店内の店員との会話から買い物を始める

記録日：2026-11-13。状態：新仕様に基づく試作。見た目は提案／要検証・利用者レビュー待ち。

関連：[Issue #21](https://github.com/kame447/gmo-security-life-game/issues/21)、[店内対応 #33](https://github.com/kame447/gmo-security-life-game/issues/33)、[買い物仕様](../features/shopping.md)。

旧PR #27は屋外や棚から一覧を直ちに開く導線と簡素なUIを利用者が受け入れず、未マージで取り下げた。新仕様は「入店→店員の挨拶→買う／やめる→商品確認→購入→店内」を必須とする。

- 内部の原子的取引だけを再利用し、旧UIと入口判定は持ち込まない。#20の資産核と共通モーダル基盤の上へ新ブランチを作る。
- 挨拶はNPC担当の既存の名前・台詞を使い、#21は選択肢と購入確認・結果を管理する。
- 店舗・入口・室内・店員キーをデータファイルに分け、#33担当が追加できる形にする。配置を買い物側から変更しない。
- 会話状態・取引を自己マウントの画面から分離し、排他制御は共通モーダルへ委ねる。
- 画面下部の会話枠に連続して一覧・詳細を広げる。アイコンはコード生成。配色・余白・枠・文字・小画面は画像と実操作でレビューする。
- 新PRは利用者のUIレビュー後に作る。単体/E2E成功だけで画面を受け入れ済みとはしない。

まとめ買い・売却・在庫・購入履歴・自販機サービスは今回の対象外または未決定。全店舗の室内制作は #33 の別担当に分離する。
