# 判断の記録

企画の正式な方針は [全体企画書](../product.md) を正本とします。このディレクトリは、方針変更時に比較した選択肢や判断理由など、企画書だけでは追跡しにくい重要な決定を残すための場所です。

決定が必要になった時点で、背景、採用する方針、理由、代替案、決定日を記載します。過去の判断を変更した場合は、変更元との関係を残します。採用していない案は [イベント候補](../events/README.md) または [演出案](../ideas/time-pressure.md) で管理します。

- [0001](0001-aws-infra-terraform.md) — AWS インフラを Terraform で管理し、CloudFront だけを公開する
- [0002](0002-infra-operations.md) — NAT なしのまま、運用・認証・ログを VPC エンドポイントと Parameter Store で賄う
