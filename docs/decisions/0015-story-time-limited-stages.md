# 0015: 序章と、制限時間・強制イベントによるステージ進行（提案／要合意）

状態：利用者の指示（2026-11-18）による提案。チームの合意待ち。[0005](0005-task-based-life-progression.md) の「時間の経過で年代を進めない」方針を変更する。

## 背景

利用者から、オープニングの後に家の2階で目覚め、町全体を強制的に回り、自転車を手に入れてから、人生ゲームのようにイベントを経験していく流れと、時間が経ったら次のステージ（中学 → 高校など）へ進む仕組みの指示があった。ただし、時間制限だけではイベントを一つも経験しない可能性があるため、いくつかを強制イベントにする。

0005 では、プレイヤーごとに探索や会話の時間が異なり、必要な行動を終える前に次へ移されるおそれがあるため、時間経過ではなく主要タスクの経験とプレイヤーの選択を年代移行の条件としていた。

## 方針

- 本編をステージに区切り、各ステージに制限時間を設ける。時間切れで次のステージへ自動的に進む。プレイヤーの選択による移行は行わない。
- 各ステージに強制イベントを置く。時刻または場所をきっかけに発生させ、時間切れの時点で未経験のものは移行前に必ず発生させる。
- 時間は探索中だけ進め、会話・選択・メニュー・演出の間は止める。
- 強制イベントの達成は経験で判定し、成功・失敗は状態へ別途反映する。セキュリティ上の正解を達成条件にしない（0005 から維持）。
- 序章（中学生の主人公が2階で目覚め、母親からスマホを受け取り、お使いで町を回り、スマホで自転車を買う）には制限時間を設けない。最初のステージは中学とする。
- 序章の自転車購入は、[SEC-002](../events/security-events.md)（偽通販サイト）を題材にした必須のセキュリティイベントとする。偽サイトで買っても行き止まりにせず、見分けられたかを達成条件にしない。
- 詳細は [ストーリーの流れ](../features/story.md) に記す。

## 理由

- 0005 の懸念（必要な行動を終える前に移される）は、強制イベントを移行前に必ず消化することで避ける。プレイヤーが経験する最低限の出来事を保証する。
- 制限時間によって、同じステージに留まり続けて利益を無制限に得る問題（0005 で未決定）を解消できる。
- 時間の限られた中で何を経験するかを選ぶことが、人生ゲームらしい「選ばなかった道」の体験になる。
- 序章のお使いで町の構造を先に把握させ、本編の限られた時間を移動先探しに費やさないようにする。
- 序章でスマホと自転車を持たせ、本編のイベントのきっかけ（スマホ）と移動手段（自転車）を揃えてから制限時間を始める。自転車の購入を通じて、最初のセキュリティイベントを全員に経験させる。

## 0005 から変わる点・維持する点

| 項目 | 0005 | 本提案 |
|---|---|---|
| 次へ進む条件 | 主要タスクをすべて経験し、プレイヤーが選ぶ | 制限時間の経過（強制イベントは移行前に必ず経験） |
| 必ず経験する出来事 | 主要タスク | 強制イベント |
| 任意の目標 | 任意タスク（移行の条件にしない） | 任意イベント（同左） |
| 同じ年代に留まる問題 | 未決定 | 制限時間で解消 |
| セキュリティ判断と達成条件 | 正解を条件にしない | 維持 |
| 過去の選択の引き継ぎ | 引き継ぐ | 維持 |

## 未決定事項

高校以降のステージの一覧、幼少期・小学生の時期の扱い、制限時間の長さと時間の換算、強制イベントの件数・内容、残り時間の表示、お使いの行き先と用事、自転車購入の所持金の出どころと偽サイトで買った後の入手手段。
