# 0004: 主要タスクと人生の節目による進行

## 背景

本作はルーレットではなく、同じ町を探索しながら幼少期から老後までを送る人生ゲームである。時間の自動経過や細かな行動ポイントのみを進行条件にすると、探索や会話の自由度と両立しにくい。

## 方針

生活上の主要タスクを経験して年代の節目を解放し、プレイヤーが選択すると次の年代へ移る。序盤は具体的な主要タスクを複数提示し、全件を経験すると節目を解放する。後半は生活上の大きな目標を示し、行動の選択はプレイヤーに委ねる。

主要タスクの達成は出来事の経験で判定し、成功・失敗の結果は人生の状態へ別途反映する。任意タスクは成長、持ち物、交友、選択肢の拡張に用いるが、年代移行の必須条件にしない。自由移動のみで年代を進めない。

インターネットやデジタルサービス利用のリスクは、日常生活の行動・イベントに埋め込む。セキュリティ上の正解や被害回避そのものを主要タスクの達成条件にしない。過去の選択は後の年代に引き継ぐ。

## 理由

プレイヤーが次の生活目標を把握できることと、失敗した場合も人生が続くことを両立するため。序盤は探索と生活の習得を支援し、後半は選択の自由度を高める。

## 未決定事項

年代ごとの主要タスク数、失敗時の代替達成ルート、任意タスクの発生条件、節目解放後の繰り返し行動への制約、日付・時間の演出、最終評価方法、実装のデータ契約・UI・保存形式は未決定。既存のセキュリティイベント候補の採用と年代分類も未決定。
