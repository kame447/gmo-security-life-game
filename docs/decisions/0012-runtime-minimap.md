# 0012: 実行中のエリアからミニマップを生成する（提案／要検証）

## 背景

Issue #15 は、現在地に追従する周辺地図と、同じエリアの全体地図を求めている。手書き画像を別に管理すると、実際の道路・建物・通行可能範囲や出入口と地図が食い違う。

## 今回の方針

- `AreaRuntime` の地面タイル、衝突索引、建物の占有範囲、有効な出入口から、タイル単位の概略地図を作る。ゲームのデータを変更せず、個別の町の座標を複製しない。
- 周辺表示は主人公の足元座標を中心に追従し、全体表示は現在エリア全体を縦横比を保って収める。どちらも現在地と向きを示す。
- 実行中のエリアオブジェクトごとに地図画像をキャッシュし、エリアの切替時は別の地図を使う。現行の実行時エリアは組立後に地形・衝突を変更しない。将来、同じオブジェクトを更新する機能を導入する場合はキャッシュ無効化が必要。
- 全体図は探索・会話・外見変更と排他的にし、開いている間はゲームの更新呼出しを止める。開閉時に押下中の移動入力を解除する。

## 制約と今後の確認

地図は占有タイルと通行可能範囲の概略であり、建物の立面や描画上の装飾まで再現しない。色・寸法・周辺範囲は試作値で、実画面の見やすさを確認する。未統合のバッグ・スマホ等との画面配置と入力の共存は、それらを統合した時点で確認する。
