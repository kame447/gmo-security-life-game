# バッグ候補の比較と一時セッション

- 状態: 利用者レビュー前の候補
- 関連: Issue #20、#21、#22

旧PR #28の画面は採用されていないため、資産・保存の内部処理だけを再利用し、新しい1層グリッドとクイック枠付きグリッドを比較する。通常／重要を区分の基本とし、クイック枠の採否は決めない。服は所持に留め、能力や装備欄を設けない。

候補ごとにDOM・CSS・アイコンを別モジュールへ置き、共通モーダル登録口で1つだけを生成する。共通コントローラーと実マップ・NPC・外見・描画は変更しない。既存のみため編集の未確定外見を保存しない処理も維持する。

比較条件を揃えるため、同じアイテム定義・資産API・暫定fixtureを使用する。レビューURLの `review=1` は読込を省略し、全保存経路の共通入口で書込を止める。通常セーブを比較操作で上書きしない。候補のURL切替はレビュー専用で、セーブ形式の設定値にはしない。

採用の判断はスクリーンショットと実ゲームの操作を利用者が確認して行う。ビルド・テストの成功は視覚品質の承認を意味しない。採用前にPRを作成せず、旧PRを再オープンしない。
