# 概念設計

[全体企画書](product.md) に示した人生シミュレーションの体験を、機能の責務に分けて整理する。

## 機能の責務

表示と入力では、ドット絵のマップ、人物、会話、選択肢、結果を表示し、プレイヤーの操作を受け取る。

探索と自由行動では、マップ上の移動や生活上の行動からイベントにつなげる。人生の進行では、年齢段階の移行と生活の変化を扱う。

イベントの進行では、発生条件、選択肢、結果、分岐を扱う。プレイヤーの状態では、年齢、能力、嗜好、資産、交友関係、職歴などと選択による変化を扱う。個別のイベントやマップなど、ゲーム内容の定義は共通の進行処理から分けて管理する。

マップの座標変換、チャンク読込、描画・カメラ、移動・衝突、出入口遷移、年代差分、イベント通知、保存・復帰を分離する。描画処理にイベント条件をハードコードしない。詳しくは [マップと探索](features/map.md)。実装言語はTypeScriptを予定し、描画エンジンは未決定。

## 状態とイベントの関係

プレイヤーの行動や選択を受け取り、イベントの結果を現在の状態に反映する。その状態を後の人生やイベントで参照し、選択の長期的な影響を表現する。

[遊びの進行](features/gameplay.md)、[プレイヤーの状態](features/player-state.md)、[イベント共通仕様](features/events.md) で機能ごとの内容を管理する。
