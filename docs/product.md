# 全体企画書

状態：企画の基本方針は合意済み。数値仕様や具体的なイベント分岐は未決定。

## 目的

人生シミュレーションを遊ぶ中で、日常のセキュリティリスク、その影響、対策を自然に学べるゲームを作ります。生活上の選択とその結果を通じて、自分の暮らしに関わる問題としてセキュリティを捉えられる体験を目指します。

## 対象ユーザー

セキュリティに詳しくない一般の人を対象とします。エンジニアや専門家向けの知識を前提にせず、状況や選択の意味が伝わるようにします。

専門的な知識の正誤を問うクイズを中心には据えません。人生を送る楽しさを主軸に、日常の場面にセキュリティ上の判断が関わるゲームです。

## 体験の核

1. マップを探索し、自由に行動しながら、人との関わりや生活上の出来事に出会う。
2. イベントで選択し、その場の結果と、能力・資産・交友・職歴などへの影響を経験する。
3. 選択の長期的な影響を受けながら人生を進め、リスクと対策を生活の文脈で学ぶ。

学校、進路、交友、仕事、恋愛、転職、結婚、介護などの生活要素を主軸とします。主人公の性格や進路を開始時の診断で固定せず、ゲーム中の行動と選択によって人生が形成されるようにします。能力や経験は進路などの選択可能性に影響し得ますが、能力値だけで詐欺やトラブルを自動的に回避する仕組みにはしません。日常イベントとセキュリティイベントの配分は **7:3〜6:4程度**を目安とします。厳密な件数、発生確率、年代ごとの配分、比率の算定方法は未決定です。

## ゲーム概要

| 項目 | 合意した方針 |
| --- | --- |
| ジャンル | 人生シミュレーション |
| 基本の遊び | マップ探索・自由行動とイベントでの選択 |
| ビジュアル | 親しみやすい2Dドット絵 |
| 人生の範囲 | 子ども〜学生〜成人〜中年〜高齢 |
| 状態の要素 | 年齢、能力、嗜好、資産、交友、職歴など |
| 選択の影響 | その場の結果に加え、その後の人生への長期的な影響を扱う |
| 通貨 | 円 |
| 開発の目標 | 数か月かけて全年代を含むゲームの完成を目指す |

ビジュアルは、親しみやすく生活感のある2Dドット絵を基本とします。町や建物の内部を見下ろし視点で探索できる表現を想定します。具体的な絵柄、画面構成、素材の仕様は今後決めます。

## 全年代のイメージ

以下は、人生全体で扱いたい生活要素をイメージするための整理です。イベントの発生年代や必須の人生経路を定めるものではありません。

| 年代 | 生活のイメージ |
| --- | --- |
| 子ども | 学校や身近な人との交友を通じて生活する |
| 学生 | 学校生活や交友を続けながら、進路を考える |
| 成人 | 仕事や恋愛、転職、結婚など、生活の選択肢が広がる |
| 中年 | 仕事や人間関係を重ね、介護など生活の変化にも向き合う |
| 高齢 | それまでの資産や人間関係、選択の影響を受けながら暮らす |

各年代の年齢範囲、移行条件、具体的な生活内容は未決定です。上記の生活要素を特定の年代だけに限定したり、すべて経験することを必須にしたりする決定もありません。既存のSEC-001〜015は、この表に割り当てず、全件を年代未分類の候補として保持します。

## 開発範囲と未決定事項

全年代の完成を目標とし、段階的に実装・検証します。初期に検証する範囲と、最終的に目指す全年代の範囲を区別します。開発の段階と完了条件は [開発ロードマップ](roadmap.md) に記載します。

以下は未決定です。

- 人生の進行速度、時間の単位、年代の区切りと移行条件、終了・評価の方法。
- 年代別の生活内容、イベント、進路や人間関係の具体的な分岐。
- マップの種類・接続・移動条件、自由行動の具体的な内容。
- アイテムを欲しくなるきっかけと、入手や購入へつなげる導線。
- パラメータの内訳、初期値、変化量、影響の計算方法。
- 個別イベントの採用、発生条件、選択肢、結果、影響、分岐。
- リスク・影響・対策の伝え方と、学びを確かめる方法。
- 対応環境、技術スタック、データの保存方式。

[イベント候補](events/README.md) と [ゲームプレイ上の工夫](ideas/time-pressure.md) は未採用の案です。SEC-001〜015や制限時間による焦りの演出を、この企画方針の合意によって採用したことにはしません。
