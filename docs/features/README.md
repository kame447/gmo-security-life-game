# 機能仕様

[全体企画書](../product.md) のゲーム体験を機能別に整理する。

[遊びの進行](gameplay.md) では主要・任意タスクと節目による年代進行、マップ探索と自由行動を扱う。[プレイヤーの状態](player-state.md) では主人公のパラメータ、タスク進捗と選択の長期的な変化、[イベント共通仕様](events.md) では日常・インターネットセキュリティイベントに共通する仕組みを扱う。

[マップと探索](map.md) には分割マップの構造、町の動線、移動・屋内外遷移・年代差分・非機能要件をまとめる。
[自転車](bicycle.md) には、屋外で自転車に乗って移動する試作の操作と未決定事項をまとめる。
[NPC のドット絵](npc-sprite.md) には、NPC を主人公と同じ画風で描く図案の作りをまとめる。

[スマートフォン](phone.md) と[通信容量](phone-data-budget.md) は端末画面の候補と未決定の通信設定を扱う。

[編集データと差分適用](editor.md) にはマップ・NPC GUIが共有するデータ契約、検証、Undo/Redo、JSON差分の出力と安全な適用をまとめる。

[所持金とバッグ](inventory.md) には資産・保存の基盤と、バッグとホットバーの共通インベントリをまとめる。

[イベント基盤](life-events.md) には、会話・選択肢・状態変化・履歴を扱う仕組みの実装範囲（試作）と未対応事項をまとめる。

[オープニングとタイトル画面](opening.md) には仮オープニングの3案をまとめる。

[ストーリーの流れ](story.md) には、オープニング後の序章（中学生の主人公が家の2階で目覚め、母親からスマホを受け取り、お使いで町を回り、スマホで自転車を買う）と、制限時間・強制イベントによるステージ進行の提案をまとめる。

[店員から始める買い物](shopping.md) には、店員の会話からの商品選択・購入・店内復帰と、承認済みの画面をまとめる。

[BGM](bgm.md) には、コードで作曲・合成するマップ探索中の BGM（試作）と未決定事項をまとめる。

個別のイベント内容は [イベント文書](../events/README.md) にまとめる。
