# 機能仕様

[全体企画書](../product.md) のゲーム体験を機能別に整理する。

[遊びの進行](gameplay.md) ではマップ探索、自由行動と人生の進行、[プレイヤーの状態](player-state.md) では主人公のパラメータと長期的な変化、[イベント共通仕様](events.md) では日常・セキュリティイベントに共通する仕組みを扱う。

[マップと探索](map.md) には分割マップの構造、町の動線、移動・屋内外遷移・年代差分・非機能要件をまとめる。

[スマートフォン](phone.md) と[通信容量](phone-data-budget.md) は端末画面の候補と未決定の通信設定を扱う。

個別のイベント内容は [イベント文書](../events/README.md) にまとめる。
