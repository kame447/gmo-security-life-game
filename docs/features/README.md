# 機能仕様

[全体企画書](../product.md) のゲーム体験を機能別に整理する。

[遊びの進行](gameplay.md) では主要・任意タスクと節目による年代進行、マップ探索と自由行動を扱う。[プレイヤーの状態](player-state.md) では主人公のパラメータ、タスク進捗と選択の長期的な変化、[イベント共通仕様](events.md) では日常・インターネットセキュリティイベントに共通する仕組みを扱う。

[マップと探索](map.md) には分割マップの構造、町の動線、移動・屋内外遷移・年代差分・非機能要件をまとめる。

個別のイベント内容は [イベント文書](../events/README.md) にまとめる。
