# 機能仕様

合意済みの方針を機能ごとに整理します。各文書には目的、責務、入力・出力、受け入れ条件、未決定事項を記載します。現在は共通の方針を記した段階であり、具体的な数値や分岐まで定めた実装仕様ではありません。

## 文書一覧

| 文書 | 扱う内容 |
| --- | --- |
| [遊びの進行](gameplay.md) | マップ探索、自由行動、生活と人生の進行 |
| [プレイヤーの状態](player-state.md) | パラメータ、円で扱う資産、選択の長期的な影響 |
| [イベント共通仕様](events.md) | 日常・セキュリティイベントに共通する進行と、詳細化する項目 |

## 他の文書との役割分担

- [全体企画書](../product.md) は、目的、対象ユーザー、体験の核、ゲーム概要、全年代のイメージを扱います。
- このディレクトリは、機能に共通する振る舞いと受け入れ条件を扱います。
- [イベント文書](../events/README.md) は、候補と、採用後に決まった個別イベントの発生条件・選択肢・結果・影響・分岐を扱います。
- [判断の記録](../decisions/README.md) は、重要な方針の決定と理由を扱います。

未決定事項を機能仕様の中で勝手に補いません。実装前に対象範囲の受け入れ条件を具体化し、仕様が変わったら対応する文書を更新します。
