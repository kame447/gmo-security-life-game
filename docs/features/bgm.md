# BGM（試作）

マップ探索中に流す BGM の試作です。経緯と受け入れ条件は [Issue #63](https://github.com/kame447/gmo-security-life-game/issues/63) で管理します。曲調の違う3案を聴き比べ、2026-11-17 に案C「わくわくストリート」を採用しました。

## 方式

- 音源ファイルは使いません。曲は音の高さと長さのデータとしてコードに持ち、Web Audio API でファミコン風の音（チップチューン）に合成します。
- 曲は Claude が作曲したもので、外部の素材を含みません。このため `assets/audio/` への追加や、出典・ライセンスの記録は不要です。
- パートは4つです：メロディ（パルス波。曲ごとに 25% または 50%）、伴奏（パルス波 12.5%・和音を1音ずつ鳴らす）、ベース（三角波）、ドラム（ノイズ・低音のキック）。
- メロディは手で書き、伴奏・ベースは「コード進行」と「1小節分の型（根音・3度・5度・オクターブの並び）」から組み立てます。ドラムも1小節分の型を並べ、8小節ごとにフィルを入れます。

| 曲名 | 雰囲気 | 調・拍子 | テンポ | 長さ（くり返し） |
|---|---|---|---|---|
| わくわくストリート | 元気・速め・冒険 | ト長調・4拍子 | 144 | 16小節・約27秒 |

本編ではこの1曲を流します。聴き比べ用だった案A「まちのうた」（ヘ長調・120）・案B「ひだまりワルツ」（ハ長調・3拍子・96）の曲データと、URL の `?bgm=` による切り替えは採用決定に合わせて削除しました（PR #64 の履歴に残っています）。

## 再生の振る舞い

- ブラウザは利用者が操作するまで音を出せないため、最初のキー操作・クリック・タッチで鳴り始めます。
- M キーでミュートを切り替え、画面に「おんがく：オフ（M）」などを短く表示します。ミュート状態は保存せず、再読み込みでオンに戻ります。
- タブが非表示の間は止め、表示に戻ると続きから鳴らします。

## ファイル

| パス | 役割 |
|---|---|
| `game/src/audio/song.ts` | 音名・コード・伴奏の型の解釈、町の曲のデータ |
| `game/src/audio/synth.ts` | 曲データを合成してくり返し鳴らす `BgmPlayer` |
| `game/src/audio/bgm.ts` | 本編への接続（再生開始・M キー・タブの表示切り替え） |
| `game/bgm-preview.html`、`game/src/audio/preview.ts` | 町の曲だけを聴く試聴ページ（開発サーバーで `/bgm-preview.html`） |
| `game/tests/bgm-song.test.ts` | 音名の変換、伴奏の型、曲の小節の長さ・音域・重なり・くり返しの長さの検証 |

試聴ページは開発サーバー専用で、`npm run build` の出力には含めません。
