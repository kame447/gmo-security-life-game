# BGM（試作）

マップ探索中に流す BGM の試作です。経緯と受け入れ条件は [Issue #63](https://github.com/kame447/gmo-security-life-game/issues/63) で管理します。曲調・テンポ・採用は利用者の試聴で判断する前提で、現時点では確定していません。

## 方式

- 音源ファイルは使いません。曲は音の高さと長さのデータとしてコードに持ち、Web Audio API でファミコン風の音（チップチューン）に合成します。
- 曲は Claude が作曲したもので、外部の素材を含みません。このため `assets/audio/` への追加や、出典・ライセンスの記録は不要です。
- パートは4つです：メロディ（パルス波 25%）、伴奏（パルス波 12.5%・裏拍の和音）、ベース（三角波）、ドラム（ノイズ・低音のキック）。
- 伴奏・ベース・ドラムはコード進行から自動で組み立て、メロディだけを手で書きます。

| 曲名 | 調 | テンポ | 長さ | 使う場面 |
|---|---|---|---|---|
| まちのうた | ヘ長調 | 120 | 16小節（約32秒）でくり返し | マップ探索中のすべての場所 |

## 再生の振る舞い

- ブラウザは利用者が操作するまで音を出せないため、最初のキー操作・クリック・タッチで鳴り始めます。
- M キーでミュートを切り替え、画面に「おんがく：オフ（M）」などを短く表示します。ミュート状態は保存せず、再読み込みでオンに戻ります。
- タブが非表示の間は止め、表示に戻ると続きから鳴らします。

## ファイル

| パス | 役割 |
|---|---|
| `game/src/audio/song.ts` | 音名・コードの解釈、曲データ（まちのうた） |
| `game/src/audio/synth.ts` | 曲データを合成してくり返し鳴らす `BgmPlayer` |
| `game/src/audio/bgm.ts` | 本編への接続（再生開始・M キー・タブの表示切り替え） |
| `game/bgm-preview.html`、`game/src/audio/preview.ts` | 曲だけを聴ける試聴ページ（開発サーバーで `/bgm-preview.html`） |
| `game/tests/bgm-song.test.ts` | 音名の変換、各小節の長さ、各パートの音域・重なりの検証 |

試聴ページは開発サーバー専用で、`npm run build` の出力には含めません。
