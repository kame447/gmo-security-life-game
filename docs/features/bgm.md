# BGM（試作）

マップ探索中に流す BGM の試作です。チームで聴き比べるため、曲調の違う3案を用意しています。経緯と受け入れ条件は [Issue #63](https://github.com/kame447/gmo-security-life-game/issues/63) で管理します。曲調・テンポ・採用は利用者の試聴で判断する前提で、現時点では確定していません。

## 方式

- 音源ファイルは使いません。曲は音の高さと長さのデータとしてコードに持ち、Web Audio API でファミコン風の音（チップチューン）に合成します。
- 3曲とも Claude が作曲したもので、外部の素材を含みません。このため `assets/audio/` への追加や、出典・ライセンスの記録は不要です。
- パートは4つです：メロディ（パルス波。曲ごとに 25% または 50%）、伴奏（パルス波 12.5%・和音を1音ずつ鳴らす）、ベース（三角波）、ドラム（ノイズ・低音のキック）。
- メロディは手で書き、伴奏・ベースは「コード進行」と「1小節分の型（根音・3度・5度・オクターブの並び）」から組み立てます。ドラムも1小節分の型を並べ、8小節ごとにフィルを入れます。

| 案 | 曲名 | 雰囲気 | 調・拍子 | テンポ | 長さ（くり返し） |
|---|---|---|---|---|---|
| A | まちのうた | 明るく弾む・ふだんの町 | ヘ長調・4拍子 | 120 | 16小節・約32秒 |
| B | ひだまりワルツ | ゆったり・なつかしい | ハ長調・3拍子 | 96 | 16小節・約30秒 |
| C | わくわくストリート | 元気・速め・冒険 | ト長調・4拍子 | 144 | 16小節・約27秒 |

本編では既定で案Aを流します。URL に `?bgm=a`・`?bgm=b`・`?bgm=c` を付けると曲を切り替えられます（聴き比べ用の仮の仕組み）。どの案を採用するか、場所ごとに使い分けるかは未決定です。

## 再生の振る舞い

- ブラウザは利用者が操作するまで音を出せないため、最初のキー操作・クリック・タッチで鳴り始めます。
- M キーでミュートを切り替え、画面に「おんがく：オフ（M）」などを短く表示します。ミュート状態は保存せず、再読み込みでオンに戻ります。
- タブが非表示の間は止め、表示に戻ると続きから鳴らします。

## ファイル

| パス | 役割 |
|---|---|
| `game/src/audio/song.ts` | 音名・コード・伴奏の型の解釈、3案の曲データ |
| `game/src/audio/synth.ts` | 曲データを合成してくり返し鳴らす `BgmPlayer` |
| `game/src/audio/bgm.ts` | 本編への接続（`?bgm=` による曲の選択・再生開始・M キー・タブの表示切り替え） |
| `game/bgm-preview.html`、`game/src/audio/preview.ts` | 3案を聴き比べる試聴ページ（開発サーバーで `/bgm-preview.html`） |
| `game/tests/bgm-song.test.ts` | 音名の変換、伴奏の型、各曲の小節の長さ・音域・重なり・くり返しの長さ、`?bgm=` の選択の検証 |

試聴ページは開発サーバー専用で、`npm run build` の出力には含めません。
