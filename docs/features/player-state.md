# プレイヤーの状態

主人公の年齢、能力、嗜好、資産、交友関係、職歴などを人生の状態として扱う。

ゲーム中の行動やイベントでの選択が状態を変化させ、その後の進路や生活の選択肢、出来事につながる。性格や進路も、プレイヤーが人生の中で積み重ねた行動と選択によって形成される。

所持金や取引の通貨は日本円とする。

所持金・所持品の現在の実装と暫定値、共通操作・閲覧・保存の仕様は [所持金・所持品・保存](inventory.md) を参照する。

[遊びの進行](gameplay.md) と [イベント共通仕様](events.md) が、この状態を参照して人生の変化と選択の影響を表現する。
