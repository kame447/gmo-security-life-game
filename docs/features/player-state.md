# プレイヤーの状態

主人公の年齢、能力、嗜好、資産、交友関係、職歴などを人生の状態として扱う。

ゲーム中の行動やイベントでの選択が状態を変化させ、その後の進路や生活の選択肢、出来事につながる。性格や進路も、プレイヤーが人生の中で積み重ねた行動と選択によって形成される。

## 人生の進行に関係する状態

年代、節目の解放状態、主要・任意タスクの進捗とイベントの経験・選択結果を、区別して保持する。

人生の節目で年代が変わる際も、資産、能力、嗜好、交友関係、所持品、職歴、過去の出来事やデジタルサービスの利用状況などを必要に応じて引き継ぐ。過去の判断が後のイベント条件になる場合には、その判断の履歴を保持する。具体的なデータ形式・保存方式は未決定。

所持金や取引の通貨は日本円とする。

[遊びの進行](gameplay.md) と [イベント共通仕様](events.md) が、この状態を参照して人生の変化と選択の影響を表現する。
