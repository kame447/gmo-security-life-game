# プレイヤーの状態

状態：扱う要素と長期的な影響の方針は合意済み。数値仕様や計算方法は未決定。

## 目的と責務

人生の現在の状態を表し、行動やイベントでの選択を、その場の変化と後の人生へつなげます。状態の要素と影響の扱いを整理し、個別イベントの変化量や分岐は [イベント詳細](../events/README.md) で決めます。

## 扱う要素

| 要素 | 合意済みの範囲 | 未決定の詳細 |
| --- | --- | --- |
| 年齢 | 人生の進行と年代を扱う | 初期年齢、進行速度、年代の区切り |
| 能力 | 能力を状態の要素として扱う | 種類、表現方法、範囲、変化量 |
| 嗜好 | 嗜好を状態の要素として扱う | 分類、決まり方、選択への関わり方 |
| 資産 | 所持金などの資産を扱い、通貨は円とする | 初期資産、収支、価格、計算方法 |
| 交友 | 人との関わりを状態の要素として扱う | 関係の種類、表現方法、変化の条件 |
| 職歴 | 仕事の経験を状態の要素として扱う | 記録する内容、進路・転職などとの関係 |

これら以外のパラメータを設けるかは未決定です。すべての要素を数値で表すことや、能力などの内訳を定めたものではありません。

## 選択と長期的な影響

行動やイベントでの選択は、現在の状態だけでなく、その後の生活にも影響します。何がどの状態に影響し、後のどの場面につながるかは、該当する機能や個別イベントを具体化する際に決めます。

影響が現れる時期、履歴として保持する情報、状態の表示範囲は未決定です。長期的な影響を実現するデータ形式や保存方式も、この文書では指定しません。

## 入力と出力

| 種類 | 概念上扱うもの |
| --- | --- |
| 入力 | 現在の状態、行動・イベントでの選択、決定済みの結果と影響 |
| 出力 | 変化後の状態、後の人生やイベントで参照する情報 |

## 受け入れ条件

- 年齢、能力、嗜好、資産、交友、職歴など、仕様化した状態の要素を人生の進行に反映できる。
- 通貨の表示と金額を扱う仕様で、円を使用する。
- 個別イベントで定めた結果・影響が状態に反映され、長期的な影響が後の生活につながる。
- 初期値、変化量、影響先などが未決定の項目を、合意済みの数値として実装しない。

具体的な値や影響の例を用いた検証条件は、対象の行動・イベントを決めた時点で追加します。
