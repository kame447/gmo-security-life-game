# 持ち物画面 A: グリッドとクイック枠（候補・未採用）

Issue #20 の比較用候補。所持品全体を4列のグリッドで表示し、選んだ品を5つのクイック枠へ割り当てる。探索中にも選択枠と個数を表示する。枠数、分類、操作、表示位置は提案／要検証であり、採用は決まっていない。

- 「ふつう」「たいせつ」の区分と、選択した品の名前・個数・説明を表示する。服は所持品として表示する。
- マウス／タッチでは品を選んでクイック枠を押す。キーでは矢印または WASD で品を選び、1〜5 で枠へ割り当てる。Esc または I で閉じる。
- 探索中の枠タップ／1〜5 は枠の選択だけを行う。アイテムの使用や効果は未実装。
- 枠は所持品の ID を参照し、個数は同じ所持品から読む。所持数が0になった枠は空にする。割り当ては候補画面内の一時状態で、再読込時の保存は未実装。

比較用 URL は `/?bag=hotbar&review=1`。`review=1` は共通の暫定サンプルで開始し、既存セーブの読込・書込を行わない。サンプル内容は `game/src/data/bag-review-fixture.ts` に置く。通常の URL は既存セーブを使う。複数候補の切替は比較用であり、正式仕様ではない。

撮影は開発サーバー起動後、`SLG_SHOTS=<出力先> SLG_URL=http://127.0.0.1:5186 node scripts/shots-bag-hotbar.mjs` を `game/` で実行する。操作確認は `SLG_URL=http://127.0.0.1:5186 node scripts/e2e-bag-hotbar.mjs` を使う。
