# 商店街・コンビニの買い物

[Issue #21](https://github.com/kame447/gmo-security-life-game/issues/21) の購入フロー。[所持金・所持品](player-state.md) と [イベント共通仕様](events.md) に接続する日常の行動として扱い、セキュリティの正解・不正解や能力変化は要求しない。

## 実装する体験

既存の対象を調べると「商品一覧 → 商品の選択・確認 → 購入結果」を表示する。購入は1回につき1個。確認時に商品名、説明、価格（円）、現在の残高、購入後の残高、所持数と上限を示す。

既定の台詞を挟まず、購入画面を直接開く方法はプロトタイプでの **提案／要検証**。`MapEventSink` の空の会話応答を使い、マップ・NPC・調査対象の定義や台詞は変更しない。他の対象では従来の会話を続ける。

| 既存 eventKey | 売り場 | 暫定商品・価格 |
| --- | --- | --- |
| `shopping.candy` | だがしやさん | おかし30円、みず100円 |
| `shopping.vending` | 自動販売機 | みず120円 |
| `shopping.konbini.snacks` | コンビニのおかし棚 | おかし50円 |
| `shopping.konbini.drinks` | コンビニの飲み物ケース | みず120円 |
| `shopping.konbini.clerk` | コンビニのレジ | おかし50円、みず120円 |

品ぞろえ・価格・商品説明・所持上限はすべて暫定例で、シナリオやゲームバランスの確定ではない。価格とeventKeyの対応は `game/src/data/shops.ts`、共通アイテムのID・名前・説明・上限は `game/src/data/items.ts` に置く。おかしは `small-snack`、水は #20 の `bottled-water`。どちらも暫定上限20個で、価格は店舗によって異なる。

## 操作と入力

- 一覧は矢印／WASDで選び、Z／Space／Enterで確認へ進む。商品ボタンのクリック・タッチでも選べる。
- 確認でZ／Space／Enterまたは「1こ かう」を押したときだけ購入する。「やめて 商品にもどる」またはEscで取り消す。
- 結果画面では決定キーを無効にする。明示的に「商品にもどる」またはEscで一覧へ戻してから次の商品を選ぶ。キーリピートでも購入を進めない。
- 一覧のEscまたは「おみせを出る」で閉じる。未確定の選択は資産に影響しない。Tab／Shift+Tabはパネル内を移動する。

買い物は探索モードからだけ開く。開いている間は移動入力を `NO_INPUT` にし、会話・外見・所持品など別の画面を開く操作を受け付けない。閉じる際に入力を解除してマップへフォーカスを戻す。タッチのAからも既存の調査操作を経由して開ける。スマホとの同時表示防止は共通のUIモード規則に従い、スマホ基盤との統合時にも確認する。

## 購入と保存

`game/src/shop/purchase.ts` はDOM非依存の小さな資産ポート（`moneyYen`、`quantity(id)`、原子的な `apply`）を使う。同じ関数を将来の別店舗やイベントから呼べる。`ShopFlow` は一覧・確認・結果の状態を持ち、確認を一度処理すると結果に留まる。

確定時に `game.assets.apply({ moneyDeltaYen: -価格, itemDeltas: [{ itemId, quantityDelta: 1 }] })` を1回呼ぶ。#20の検証で残高不足、個数上限、未知のアイテムなどが失敗した場合、所持金と所持品の全体を変えない。画面側で別々に減額・加算しない。結果は成功・残高不足・個数上限・その他の購入不可を表示する。

成功後は既存の保存処理を即時呼び出す。#20のv1セーブの `assets` 欄を使い、買い物独自の保存欄は増やさない。未確定の確認画面や結果画面は保存せず、再読込では探索へ戻る。保存が使えない環境での扱いは既存の保存基盤に従う。

## 検証と対象外

Vitestで資産ポート、成功・残高不足・取消・個数上限・確定の連打・キーリピート、全eventKeyの商品参照、#20の実資産とJSON保存・復帰を検証する。UIモードと入力の競合もDOM非依存の振り分けテストで確認する。

`game/scripts/e2e-shop.mjs` は実キーで既存店舗を調べ、クリック・タッチ、購入前の確認、取消、連打、所持品表示、再読込、入力停止を検証する。実行方法と結果は [game/README.md](../../game/README.md) に記録する。Codex sandbox内ではChromiumを起動できないため、実行は親の環境へ依頼する。

売却、数量のまとめ買い、在庫、消費、購入履歴、年齢や時間による品ぞろえ、実決済は対象外。店舗・NPCの追加や配置変更、マップ編集、既存セキュリティイベント候補の採用判断も行わない。
