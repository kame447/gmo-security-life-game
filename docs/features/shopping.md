# 店員から始める買い物

[Issue #21](https://github.com/kame447/gmo-security-life-game/issues/21)。店内で店員に話しかけると、店員の挨拶・商品一覧・選択中の詳細・所持金を同時に表示する。買い物を始めるための追加ボタンや、挨拶を送る操作は挟まない。画面は1つとし、店内が見える小さなパネルにまとめる。

## 流れ

店員へ1回決定するだけで、商品を選べる。挨拶は既存の店員名と先頭の台詞を使う。商品行の選択だけでは支払わない。「選ぶ」から確認へ進み、商品・個数・合計・所持金・購入後の残高を確認して「購入する」で確定する。結果は店員の短い応答として表示し、同じ店内へ戻る。

会話・一覧・詳細・確認の領域は重ねない。余白とパネルの大きさを抑え、PC・縦・横の画面で操作できるようにする。配色や具体的な寸法は利用者の再レビュー前であり、最終採用済みとは扱わない。

接続は `data/stores.ts` の店内エリアID・店員イベントキーを使う。この枝では既存コンビニ1件を対象とし、屋外の店先・自動販売機・棚・別室からは購入画面を開かない。他店の室内・店員・入口は #33 の範囲であり、この画面では配置データを変更しない。

## 入力と取引

- 商品は上下／W・Sで選択し、Z／Enter／Spaceで確認へ進む。クリック／タッチで商品を選んだ後も、支払いは別に確定する。
- 確認中は左右／A・Dや＋／−で個数を変える。上下／W・Sで購入・戻るを選べる。
- フォーカス中のボタンを決定キーで操作すると、そのボタンだけを実行する。取消・閉じるから購入へ振り分けない。
- Escは確認中なら一覧へ戻り、一覧・結果からは店内へ戻る。Tabは表示中の有効なボタンを移動する。
- 開くだけ・選ぶだけ・取消・残高不足・個数上限では資産を変えない。確定キーのリピートで重複購入しない。
- パネル中は共通モーダル基盤で移動・通常会話・外見・他パネルとの入力を隔離する。閉じるとマップへフォーカスを戻し、探索を再開できる。

商品と単価は `data/shop-catalogs.ts`、品目定義と資産APIは #20 を共有する。現在の商品・価格・初期資産・数量操作の上限は暫定であり、正式な品ぞろえや販売方式を決めるものではない。

`shop/purchase.ts` は資産ポートの `apply({ moneyDeltaYen, itemDeltas })` を1回だけ呼ぶ。所持金と所持品は同時に更新し、失敗時は両方とも変えない。`ClerkFlow.openShop` は挨拶の内容を保ったまま一覧から開始し、取引は確認段階でだけ受け付ける。成功時は通常の保存処理を直ちに呼ぶ。

通常保存では資産・スマホの所持状態と通信残量・会話履歴・位置・外見を共通のv1データに保持する。買い物画面はスマホ画面や通信容量の消費を追加しない。不正な位置を修復しても、有効な他の保存欄は保持する。

## レビュー用の一時セッション

```text
http://127.0.0.1:5182/?review=1
```

`?shop=`での候補切替は廃止する。`review=1`では既存セーブを読まず、共通の一時資産で、既存コンビニ内の到達できる店員の隣から買い物画面を開く。マップやNPCの配置は変えない。

購入・定期保存・リセット・みための決定・離脱を含め、通常セーブへの保存を止める。レビュー中の購入は再読込時に初期状態へ戻る。`review=1`がない通常起動は、探索からの入店と既存の保存・復帰を使う。

## 検証と撮影

```sh
cd game
npm ci --cache /private/tmp/slg-npm-cache
npm run build
npm test
npm run dev -- --host 127.0.0.1 --port 5182 --strictPort
```

ブラウザはheadlessでsandbox外の実行担当へ依頼する。

```sh
SLG_URL=http://127.0.0.1:5182 node scripts/e2e-shop.mjs
SLG_URL=http://127.0.0.1:5182 node scripts/e2e.mjs
SLG_URL=http://127.0.0.1:5182 SLG_SHOTS=/private/tmp/slg-audit/ui-review/shop-ui/HEAD node scripts/shots-shop.mjs
SLG_URL=http://127.0.0.1:5182 SLG_VIDEOS=/private/tmp/slg-audit/ui-review/shop-ui/video node scripts/video-shop.mjs
```

専用E2EはPC・390px縦・844px横で、1回の会話開始直後からの選択、会話と商品の非重複、ボタンの中心と四隅の到達性、キーボードとタッチ、取消、原子取引、連打、移動停止と復帰、不足・上限、即時保存と復帰を扱う。通常の購入・定期保存・実pagehide後の資産/phone/chat/位置/外見と、レビュー時の保存隔離も照合する。時計で進む返信待ち時間の保持は単体テストで扱い、ブラウザの保存比較には返信待ちがない完了済み会話を使う。

撮影は3サイズで開いた直後・商品選択・確認・取消後・不足・購入結果の18枚。録画は3サイズで、店員への1操作から商品選択・不足・確定・同じ店内への復帰までを残す。書き込みは指定の出力ディレクトリのみとする。
