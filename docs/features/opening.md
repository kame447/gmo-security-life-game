# オープニングとタイトル画面（候補・未採用）

ゲーム起動時の演出とタイトル画面「回避！人生の落とし穴」の候補を3案まとめる。経緯と受け入れ条件は [Issue #50](https://github.com/kame447/gmo-security-life-game/issues/50) で管理する。

**3案とも採用未決定。** 利用者が動くプレビューを比較して決めるまで、本編の入口（`game/index.html`、`game/src/main.ts`）には接続しない。

## 確認方法

```sh
cd game
npm install
npm run dev -- --host 127.0.0.1
```

`http://127.0.0.1:5173/opening-preview.html` を開く（ポートは起動時の表示に従う）。画面上部の欄は比較専用で、ゲーム画面には含めない。

| 欄 | 役割 |
|---|---|
| 案A／案B／案C | 案の切り替え。URL の `?v=a` などでも指定できる |
| もう一度再生 | 演出を最初から再生する |
| 保存データあり | 「つづきから」を選べる状態と選べない状態を切り替える |
| 動きを減らす | 演出を再生せず、最後の画面を短い明転で表示する |

## 3案

| 案 | 構図 | 動き |
|---|---|---|
| A | 見下ろしの交差点 | 「回避」が左から横にすべり込み、「！」と「人生の落とし穴」が1文字ずつ降って着地する。地面が割れて落とし穴が開き、「！人生の落とし穴」だけが落ちて穴の底で止まる。「回避」は地上に残り、最後に光の帯が1度横切る |
| B | 本編と同じ見下ろしの町の丁字路 | 主人公が下の道から丁字路へ歩いてきて、左右を見比べて左へ進む。目の前のいつもの道に落とし穴が開き、引き返して右の道を選んだところで「回避！」「人生の落とし穴」が現れる |
| C | 落とし穴の底から見上げる | 丸い穴の口から空が見える。口へ向かって上昇して地上へ抜け、町の全景がせり上がる。「回避！」が押され、「人生の落とし穴」が続く |

案A・案Bは、2026-11-14 の利用者レビューを受けて作り直した（経緯は Issue #50）。案Cは変更していない。

- 案A：「回避」の2文字は最初から最後まで高さを変えず、落とし穴の範囲にも入らない。動くのは最初の横へのすべり込みと、地割れの間の左右 1px の揺れだけにする。画面の揺れも横方向だけ。羽の演出は不採用で、画像もコードも残していない。タイトル画面では、地上の「回避」と、穴の底の「！人生の落とし穴」でタイトルを読ませる。待機中は約6秒ごとに光の帯が「回避」を横切る。
- 案B：主人公が落とし穴を跳び越える旧案は不採用。人生の選択（分かれ道で選び、選び直す）と、日常に潜む落とし穴（いつもの道に開く穴）を、文字や説明を足さずに動きだけで見せる。主人公は跳ばない。

どちらの扱いも候補であり未決定。

## 操作

本編と同じ割り当てにする。

| 場面 | 操作 |
|---|---|
| 演出中 | Z／Space／Enter／Esc、または「スキップ」でメニューへ進む |
| メニュー | ↑↓／W・S で選び、Z／Space／Enter で決定。クリック・タップでも選べる |

メニューは「はじめから」「つづきから」の2項目。「つづきから」は保存データがあるときだけ選べ、あるときは初期選択にする。プレビューでは選んだ項目を上部の欄に表示するだけで、本編の開始や保存データの変更は行わない。

## 画面サイズとアクセシビリティ

- 論理サイズは中央の 240×270 を必ず表示し、横長の画面では幅を 480 まで、縦長の画面では高さを 480 まで広げる。タイトルと主な動きは中央の範囲に収める。
- 拡大率は 0.5 刻み（高精細な画面は 0.25 刻み）に切り下げる。
- OS の「視差効果を減らす」設定（`prefers-reduced-motion`）が有効なら、演出を再生せずタイトル画面を表示する。
- スキップとメニューは通常のボタンで、キーボードのフォーカスと読み上げに対応する。タイトルは見出しとして読み上げられる。タップする部品は 44px 以上。
- 音は付けていない。

## 構成

| 配置 | 責務 |
|---|---|
| `game/opening-preview.html` | 比較用ページ |
| `game/src/opening/core.ts` | 時間の区間と補間、論理サイズ、ロゴの文字配置、メニューの状態、キーの割り当て（DOM 非依存） |
| `game/src/opening/glyphs.ts` | タイトル文字を1文字ずつドット絵調のスプライトにする |
| `game/src/opening/art.ts` | 画像の読み込み。読めない画像はコードで描いた仮の絵で代用する |
| `game/src/opening/scene-a.ts`・`scene-b.ts`・`scene-c.ts` | 各案の演出。時刻だけで絵が決まる |
| `game/src/opening/motion-a.ts`・`motion-b.ts` | 案A・案Bの時間割りと位置計算（DOM 非依存）。「回避」の位置、落ちた文字の止まる位置、主人公の動き |
| `game/src/opening/opening.ts` | 再生、スキップ、メニュー、画面サイズへの追従 |
| `game/src/opening/preview.ts` | 比較用ページの切り替え欄 |
| `game/tests/opening-core.test.ts` | `core.ts` の単体テスト |
| `game/tests/opening-scenes.test.ts` | 案A・案Bの動きの単体テスト。「回避」が全時刻で下へ動かず穴の範囲に入らないこと、主人公が跳ばず穴に入らないこと、不採用の演出と画像が残っていないこと |

案Bは本編の描画をそのまま使う。地面は `drawGroundTile()`、木・街灯・ベンチなどの小物は `objectSprite()`、主人公は `playerSprite()`（既定の外見）で、2倍に拡大して描く。落とし穴は案Aの画像を縮小して使う。

## 素材

案Aの背景と落とし穴、案Cの3点、土けむりの計6点は画像生成で作成し、`assets/images/branding/title/` に置く。案Bは画像生成を使わず、本編の描画コードと案Aの落とし穴の画像で描く。レビューで不採用になった羽と横スクロール用の6点は外した。生成手段、プロンプト、加工、利用条件の確認状況は [出自記録](../../assets/images/branding/title/PROVENANCE.md) にまとめる。タイトル文字は画像にせず、端末のフォントをコードで2値化して描く。
