# 探索画面の文章削減（比較候補・未採用）

main `5b1daa9` の探索 HUD、メニュー、タッチ操作、会話の進行表示を比べるための試作。画面表示・文言・表示時間・場所は提案／要検証であり、正式な仕様ではない。

| 比較URL | 対象がないときの操作案内 |
| --- | --- |
| `/?hint=quiet&review=1` | 常時の操作案内を表示しない。 |
| `/?hint=first&review=1` | ページを開いた最初の6秒だけ短い案内を表示する。再読込時は再表示する。 |

どちらも、調べられる対象の正面では対象名と操作を短く表示する。メニューの `?` で移動・走る・調べる・タッチの操作を確認でき、キーボードでも開閉できる。場所名、NPC の台詞、看板、外見パネルは変更しない。会話の進行表示は記号にし、タッチの決定ボタンや支援技術向けの操作名は残す。

`review=1` は比較用の一時セッションで、既存セーブを読まず書かない。通常URLの保存互換性は共通の保存基盤で別途検討する。

比較画像は `game/` で、main を別ポートで起動した上で次を実行する。`SLG_SHOTS` 配下にのみ画像を保存する。

```sh
SLG_BEFORE_URL=http://127.0.0.1:5197 SLG_AFTER_URL=http://127.0.0.1:5192 SLG_SHOTS=/path/to/shots node scripts/shots-text-trim.mjs
SLG_URL=http://127.0.0.1:5192 node scripts/e2e-text-trim.mjs
```

1280×800、390×844、844×390 の探索・タッチ・対象・会話を同条件で撮影する。`quiet` と `first` は操作案内を開いた状態も撮る。案内の発見性や、キーボード・タッチ双方での使いやすさは実画面で比較する。
