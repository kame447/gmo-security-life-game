# ゲーム内スマートフォン

対象: [Issue #22](https://github.com/kame447/gmo-security-life-game/issues/22)。見た目と操作は利用者のレビューを待つ候補であり、採用済みではありません。

## 画面候補

端末のホームはアプリアイコンを中心にし、時刻・電波・電池・通信残量をステータスバーへ置きます。390px幅では４列で、アイコンは64〜70px、タップ範囲は44px以上です。メッセージの未読はアイコン上のバッジで示します。メッセージと Web はゲーム内のサンプルで、外部サイトや実アカウントへ接続しません。生活・交流の入口は準備中です。アプリ名や表示内容も暫定で、人物・シナリオを決めるものではありません。

開く・戻る・ホーム・閉じるをクリック／タッチ、またはキーボードで操作できます。P で開き、矢印／Tab で選択、Enter／Space／Z で決定、Backspace で戻る、H でホーム、Esc で閉じます。開いている間は探索入力を止め、会話や別パネル中は開けません。

## メッセージ候補

３人の暫定的な相手を、アイコン・直近のメッセージ・時刻・未読とともに一覧表示します。相手を選ぶと、送受信を左右に分けたスクロール可能な会話が開きます。入力欄で Enter を押すか送信ボタンを操作すると即座に表示され、あらかじめ用意したローカルの返信が続きます。人物名、台詞、返信の間隔はレビュー用であり、ストーリーを採用したものではありません。実際の通信、他プレイヤー、外部 API、AI 会話は使いません。

入力中の文字・方向キーや Esc はゲーム操作へ渡さず、Esc で未送信の文章を失いません。入力は最大280 Unicode code points、制御文字を除去し、送信と受信の文字は textContent で表示します。未読は開いた会話だけ既読になり、一覧とホームの表示に反映されます。送信は `networkAllowed` に従います。返信の経過時間は実行中の時間だけを使い、pause・非表示・終了中は進みません。

`phone.chat` には会話・未読・返信待ちを保存し、旧 v1 に chat 欄がない場合は暫定の初期会話を使います。表示中の画面と未送信の入力は保存しません。履歴は相手ごとに40件、返信待ちは４件、chat全体は256KiBまでに制限します。将来の NPC やイベントはローカルの受信 API へ接続できますが、具体的な人物・イベントは未決定です。

凍結中のバッグ・買い物の旧 codec は新しい chat 欄を保持できません。３機能を通常保存で一緒に使う前に、共通 codec の更新と実際の保存・再読込の確認が必要です。

## 所持と通信

基盤段階の初期所持は設定で切り替えられ、入手時期・方法は未決定です。自宅外で開いている間は通信残量が経過時間に応じて減り、自宅内では減りません。所持・開閉・場所・表示状態・pause と保存の境界で計算を更新します。保存されるのは所持状態と残量で、開いている画面やサンプル通知は復元しません。

上限、消費速度、補充、枯渇時の制限、pause・非表示・ゲーム終了中の扱いは未決定です。設定項目、暫定値、旧保存と不正値の扱いは[通信容量](phone-data-budget.md)を参照してください。ステータスバーの時計はレビュー用の端末時刻で、ゲーム内時間の仕様を決めるものではありません。

## 確認方法

`game/scripts/shots-phone.mjs` はホーム・一覧・会話・送信後・返信後などをデスクトップ・縦長・横向きで撮影し、`SLG_SHOTS` だけへ保存します。`game/scripts/video-phone.mjs` は会話を含む遷移を `SLG_VIDEOS` へ録画します。`game/scripts/e2e-phone-simple.mjs` は端末の開閉と入力隔離、所持・残量の保存、小画面の寸法を確認し、`game/scripts/e2e-phone-chat.mjs` は会話の送受信・未読・保存・タッチ・文字列の安全な表示を確認します。`SLG_URL` は対象の開発サーバーです。画面の品質や採用はスクリーンショットと実操作のレビューで判断します。

レビュー専用の `?review=1` は既存のセーブを読まず、ゲームの自動保存も書き込みません。通常 URL は位置・外見・資産・スマホを同じ v1 セーブへ保存し、位置が不正でも有効な他の欄を保持します。
