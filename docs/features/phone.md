# ゲーム内スマートフォン

関連: [Issue #22](https://github.com/kame447/gmo-security-life-game/issues/22)、[遊びの進行](gameplay.md)、[判断記録 0006](../decisions/0006-phone-foundation.md)

## 試作中の画面

探索中に端末を開き、ホームのアプリアイコンまたは通知から画面へ進む。「もどる」「ホーム」「とじる」を端末内で選べる。メッセージとゲーム内の擬似 Web は架空の内容で、実サイト・外部サービス・実アカウントへ接続しない。生活サービスと交流の入口は準備中と表示し、未実装の機能を利用可能に見せない。

端末の外枠、ドット調のアイコン、色、壁紙、文言、アプリ配置はレビュー用の提案／要検証。具体的な人物・サービス・シナリオ・通知内容の採用は未決定。アイコンと装飾はコードで描画する。ブラウザのスクリーンショットと実際の操作を利用者が確認するまで、見た目を採用済みとしない。

## 操作と状態

基盤検証中はスマートフォンを最初から所持する。入手時期や方法は未決定で、初期値と `game.phone.setOwned()` によって利用可否を変えられる。アプリ・画面・通知の定義は `src/phone/content.ts`、状態と画面遷移は `src/phone/model.ts` に分け、`setContent()` から後続の生活行動・イベントがローカル表示データを更新できる。画面のリンク先はゲーム内 ID に限る。

起動キー P と「スマホ」ボタンは仮置き。タッチ・クリックのほか、矢印キーで対象を選び、Enter／Space／Z で決定できる。Backspace は前へ、H はホームへ、Esc は閉じる。Tab は端末内を巡回する。会話や別パネル中は起動できず、開いている間は探索入力を停止する。

既存 v1 セーブの `phone` 欄には所持状態だけを保存する。欄がない旧セーブや不正値は初期所持設定へ戻し、正常な位置・外見は維持する。開閉・画面履歴・サンプル通知は保存せず、再開時は端末を閉じる。保存が使えなくても探索を継続する。所持金・バッグとの共存は共通保存の統合時に再検証する。
