# バッグ・所持金・保存

[Issue #20](https://github.com/kame447/gmo-security-life-game/issues/20) の第二波試作。旧PR #28は未マージで取り下げられたため、内部の資産・保存処理を再利用し、画面を新しく作る。現在は利用者による見た目・操作レビュー前で、画面の承認やmainへの反映は済んでいない。

## バッグ画面の提案

町のドット絵に合わせた緑の布・クリーム色の紙・角のある枠を使い、バッグ・硬貨・所持品のアイコンをコードで描く。カテゴリ・配色・アイコン・文字・配置・操作キーは提案／要検証。

- 「ぜんぶ」「ぶんぼうぐ」「のみもの」「そのほか」のポケットを切り替える。新しいカテゴリの品も「そのほか」に入る。
- アイコン・品名・数量を持つスロットから選び、選択枠と詳細欄で対象を示す。詳細は品名・説明・数量・分類を表示する。
- 所持金を画面上部へ分ける。空のバッグと、品のないポケットを区別する。空になったときは前の品の詳細を消す。
- デスクトップはポケット・一覧・詳細を並べ、小画面は縦に配置する。短い画面は本文をスクロールでき、閉じる操作は上部に残す。
- この画面は選択と閲覧のみ。使用・譲渡・装備の操作は置かず、詳細を確認しても資産を変えない。

探索中に「もちもの」またはIで開き、I・Esc・「とじる」で閉じる。矢印／WASDで品、Q／Eでポケットを選ぶ。カテゴリと品はクリック・タッチでも選べる。Tab／Shift+Tabは画面内を循環し、Enter／Spaceは焦点のあるボタンを通常どおり押す。カテゴリに焦点がある左右キーはカテゴリを切り替える。

会話・外見・買い物・スマホとの排他、移動・タッチ入力の停止、起動ボタンの制御は共通モーダル登録APIが担当する。バッグのDOM・CSS・アイコンは自分のモジュールで生成し、起動ボタンは「みため」の後の `#menu` 内、画面本体は `#stage` 内へ置く。

## 状態と共通API

`state/assets.ts` の `PlayerAssets` を `game.assets` から参照する。金額は円単位で0以上の安全な整数、所持品はIDごとの正の整数を一つに集約する。0個の行は取り除く。

| API | 内容 |
| --- | --- |
| `moneyYen` / `quantity(id)` | 残高・個数を読む。未所持／未知IDの参照は0 |
| `snapshot()` | 保存・閲覧用のコピーを取得する |
| `changeMoney(deltaYen)` | 円単位で増減する |
| `addItem(id, n)` / `removeItem(id, n)` | 正の整数個だけ増減する |
| `apply({ moneyDeltaYen?, itemDeltas? })` | 金額と `{ itemId, quantityDelta }` の配列をまとめて検証し、全体を一括更新する |

戻り値は `{ ok: true }` または `{ ok: false, reason }`。理由は `invalid-amount`・`insufficient-funds`・`money-limit`・`unknown-item`・`insufficient-items`・`quantity-limit`。不正な整数、残高不足、数量不足、上限超過ではどの資産も変えない。消費・譲渡・売却の効果と採用範囲は未決定。

アイテムのID・名称・説明・カテゴリ・上限は `data/items.ts`、初期所持金は `data/player-defaults.ts` に置く。初期1,000円、ノート・えんぴつ・みず、上限99・99・20は仮値で、企画確定ではない。価格は買い物側のデータに置く。ポケット定義・選択は `ui/bag-model.ts`、アイコンは `ui/inventory-icons.ts`、画面は `ui/inventory-panel.ts` とCSSへ分ける。アイコンはオリジナルのコード描画で、第三者素材を使わない。

## 保存と修復

保存キー `slg-map-save-v1` と `v: 1` を保ち、任意欄 `assets: { moneyYen, items }` を加える。

- 資産欄のない旧v1は仮の初期資金と空の品で復帰し、位置・外見を保持する。
- 資産欄があるのに金額が不正なら金額だけ0へ戻す。有効な0円を初期資金へ戻さない。
- 品の不正・未知ID・0以下・小数・安全な整数範囲外の行は除く。有効な重複は集約して上限へ収める。他の有効な品と金額は保つ。
- 対応v・年代差分なら不正な位置・向き・未知エリアだけ開始地点へ戻し、外見・資産は保つ。
- JSON全体の破損や未対応v・年代差分では初期状態へ戻る。保存先が利用できなくても探索は続ける。

外見の未確定プレビューは保存しない。バッグの選択・ポケット・開閉は一時状態で、保存しない。「さいしょから」は位置の復帰で、外見・所持金・所持品を保持する。
