# 所持金・所持品・保存

[Issue #20](https://github.com/kame447/gmo-security-life-game/issues/20) の実装仕様。買い物やイベントが共通に使う状態と操作、所持品の閲覧、既存セーブとの共存を扱う。マップ・NPCの配置は対象外。

## 状態と暫定データ

所持金 `moneyYen` は0以上の安全な整数で、単位は日本円。上限は JavaScript の `Number.MAX_SAFE_INTEGER`。所持品は `itemId` と正の整数 `quantity` の組で管理し、同じIDは一つに集約する。0個になった行は取り除く。

定義は [data/items.ts](../../game/src/data/items.ts) に分け、ID・表示名・説明・カテゴリ・所持上限を持つ。今回のノート・えんぴつ・みずと、その所持上限99・99・20は動作確認用の暫定データ。初期所持金1,000円は [data/player-defaults.ts](../../game/src/data/player-defaults.ts) の仮値で、初期所持品は空。初期資金・商品採用・所持上限・操作キーは提案／要検証であり、企画上の決定ではない。価格はこの基盤に持たせず、買い物側のデータで管理する。

## 共通API

[state/assets.ts](../../game/src/state/assets.ts) の `PlayerAssets` を `game.assets` から参照する。DOM・保存先・マップに依存しない。

| 操作 | 内容 |
| --- | --- |
| `moneyYen` | 現在の残高を参照する |
| `quantity(itemId)` | 個数を参照する。未所持・未知のIDは0 |
| `snapshot()` | 金額と所持品のコピーを返す。返却値の変更は実状態に影響しない |
| `changeMoney(deltaYen)` | 円単位で増減する。0は変更なしとして許可する |
| `addItem(itemId, quantity)` | 既知の品を正の整数個追加する |
| `removeItem(itemId, quantity)` | 既知の品を正の整数個減らす |
| `apply({ moneyDeltaYen?, itemDeltas? })` | 金額と複数の品を一括更新する。個数差分は `{ itemId, quantityDelta }` の配列で、同一IDは合算して判定する |

更新結果は成功時 `{ ok: true }`、失敗時 `{ ok: false, reason }`。失敗時には金額・個数のどちらも変更しない。理由は `invalid-amount`、`insufficient-funds`、`money-limit`、`unknown-item`、`insufficient-items`、`quantity-limit`。

小数・非数値・無限大・安全な整数の範囲外は更新しない。個数差分0は不正、残高不足・未所持品の減算・上限超過も失敗とする。買い物は代金の減算と品の追加を一つの `apply` に渡すことで、品だけ・代金だけが反映されることを防げる。消費・譲渡・売却の効果や画面は今回実装しない。

## 閲覧と入力

探索中に「もちもの」ボタンまたは `I` で開き、所持金・所持品・個数・説明を確認する。空の場合は専用の案内を表示する。`I`・`Esc` または「とじる」で閉じる。ボタンはタッチでも操作できる。操作キー・文言は提案／要検証。

会話中・外見変更中には開かない。表示中は移動・会話・別パネルの起動を止め、背後のメニュー・タッチ操作・ヒントを隠す。開閉時に押下状態を解除し、閉じた後はマップへフォーカスを戻す。Tab／Shift+Tab は閉じるボタンへ移動する。

「さいしょから」は既存の開始地点への復帰操作で、所持金・所持品・外見を保持する。資産を消去する新規ゲーム操作は今回追加しない。

## v1の保存互換と修復

保存先 `slg-map-save-v1` と `v: 1` は維持し、位置・外見と同じデータに任意欄 `assets: { moneyYen, items }` を追加する。定期保存・エリア遷移・ページ離脱で保存する。既存の外見変更の未確定プレビューは引き続き保存しない。

- `assets` のない旧セーブは仮の初期資金と空の所持品で復帰し、既存の位置・外見を保持する。
- `assets` があるのに残高が不正なら残高だけ0円に修復する。有効な0円を初期資金に戻さない。
- 不正・未知ID・0以下・小数・範囲外の数量は除外する。有効な重複数量は合算し、データ上の所持上限までに収める。所持品欄全体が不正なら空にする。有効な金額や他の品は保持する。
- 対応する `v` と年代差分IDなら、不正な位置・向き・未知エリアは位置だけ開始地点へ戻し、外見・資産は保持する。
- JSON全体が壊れている、形式のバージョンや年代差分IDが未対応の場合は全体を読み込まず初期状態から再開する。ストレージが利用できなくても探索は継続する。

保存対象は金額・所持品まで。年齢進行・能力・交友・職歴・イベント履歴などは未実装で、この文書から仕様確定とみなさない。
