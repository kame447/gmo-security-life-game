# NPC のドット絵

対象: [Issue #15](https://github.com/kame447/gmo-security-life-game/issues/15) の残件「NPC の画風統一」。2026-11-18 に実画面で見た目を確認しました。その後の指摘（せんせいのめがね・おかあさんのスカート・ねこの顔の幅）を直した版は再確認待ちです。

## 方針

NPC を主人公（`game/src/render/player-sprite.ts`）と同じ形式で描きます。図案は 1 文字 = 1 ドットの文字列で、画像は読み込みません。コードは `game/src/render/npc-sprite.ts` に置きます。輪郭・肌・目・靴下などの色は主人公と共通です。

- 大きさは主人公と同じ 18×26 ドットで、足元が下端です。原点・向き（4 方向）・歩きの 3 こまは以前と変わりません。
- 子ども（ともだち・クラスのともだち）は、主人公の頭と胴の図案を流用し、色だけを変えます。
- 大人は頭を 12×12 と小さくし、胴 9 行・脚 5 行にして背を高く見せます。髪型（みじかめ・ながい・おだんご・ひとつむすび）と服（上着・ネクタイ・胸の帯と名札・前かけ・反射材のベスト・スカート・カーディガン）を組み合わせ、帽子や長いスカートのすそは上から重ねます。
- ねこは専用の図案です。正面は顔の幅を 12 ドットに抑え、目に光を入れ、耳の内側とほおを桃色にしています。歩くときは足だけを動かします。

| ID | 名前の例 | 見た目 |
|---|---|---|
| mother | おかあさん | ながい髪・ピンクの上着・足首までの長いスカート（靴だけ見える） |
| grandma | きんじょのおばあさん | 白髪のおだんご・むらさきのカーディガン・長いスカート |
| guard | みまもりのひと | 黄色い帽子・反射材のベスト |
| shopkeeper | だがしやさん | みどりの前かけ |
| staff | えきいんさん | 紺の制帽・制服・ネクタイ |
| teacher | せんせい | カーディガンとシャツ |
| clerk | てんいんさん | ひとつむすび・胸に帯のある制服・名札 |
| friend | ともだち | みどりの帽子・オレンジの上着 |
| classmate | クラスのともだち | 黄色いリボンのひとつむすび・ピンクのシャツ |
| cat | ねこ | 茶トラ（正面ではしっぽが右に見える） |

NPC には、主人公の外見で選べる髪の色・服の色を使いません。主人公と同じ見た目の NPC を作らないためです（[Issue #25](https://github.com/kame447/gmo-security-life-game/issues/25)）。配置データにない ID が来たときは、特徴の少ない大人の姿で描きます。

## 駐車中の車

町に置かれた車（`car`、2×1 タイル）も同じ形式で描き直しました（`game/src/render/car-sprite.ts`）。斜め上から見た形で、屋根と肩の面を明るく、側面を下ほど暗くし、タイヤと足元の影を付けて立体感を出しています。大きさ・当たり判定・色の候補 4 種は以前と同じです。

## 確認方法

- `game/tests/car-sprite.test.ts`：車の図案が 2×1 タイルに収まり、すべての色の記号が定義されていることを確かめます。
- `game/tests/npc-sprite.test.ts`：図案の大きさ、すべての色の記号が定義されていること、実際の町に置かれた NPC がすべて専用の図案を持つこと、主人公の色と重ならないことを確かめます。
- `game/scripts/e2e.mjs`：主人公の外見を変えても NPC の画素が変わらないことを確かめます。
- 見た目の良し悪しは、画面を見てのレビューで判断します。
