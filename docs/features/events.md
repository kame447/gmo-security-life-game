# イベント共通仕様

イベントは日常生活の状況を提示し、プレイヤーが行動を選ぶことで、その結果と影響が生じる仕組みとする。マップ探索や自由行動からイベントにつなげ、選択の影響を [プレイヤーの状態](player-state.md) とその後の人生に反映する。

## イベントの種類

学校、進路、交友、仕事、恋愛、結婚などの日常イベントと、日常に潜むリスクを扱うセキュリティイベントを組み合わせる。イベントの比率は日常対セキュリティでおおむね7:3〜6:4を目安とする。

セキュリティイベントでは、生活の状況と選択の結果を通じてリスク、影響、対処方法を伝える。

## 個別イベントの管理

個別イベントには、題名、発生する状況、発生条件、選択肢、結果、プレイヤーの状態への影響、その後の分岐を記載する。金額は日本円で扱う。

具体的なイベント内容は [イベント文書](../events/README.md) にまとめる。
