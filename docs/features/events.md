# イベント共通仕様

状態：共通方針を整理したもの。個別イベントの採用・発生条件・分岐は未決定。

## 目的と責務

生活の出来事を、状況、選択、その結果と影響を通じて経験できるようにします。日常イベントとセキュリティイベントに共通する進行を扱います。個別の内容は [イベント文書](../events/README.md) に記載します。

## 生活の中での位置づけ

[マップ探索や自由行動](gameplay.md) からイベントにつながり、選択の結果を [プレイヤーの状態](player-state.md) と後の人生に反映します。発生の具体的な契機、順序、頻度は未決定です。

生活要素を主軸とし、日常イベントとセキュリティイベントの配分は7:3〜6:4程度を目安とします。この比率を個々のイベントの発生確率として固定したり、すべての年代に同じ比率を割り当てたりする決定はありません。厳密な件数と算定方法は未決定です。

セキュリティイベントでは、専門用語の知識を前提にせず、生活の文脈でリスク・影響・対策を自然に学べることを目指します。選択後の説明など、具体的な伝え方は未決定です。

## 個別イベントで記載する項目

以下は文書で確認する項目であり、実装用のデータ形式ではありません。決定した範囲だけを記載し、残りは未決定と明示します。

| 項目 | 記載内容 |
| --- | --- |
| ID・題名 | 候補や仕様を追跡するための識別子と名前 |
| 状態 | 候補・採用済みなど、合意した採否と詳細化の状態 |
| 年代 | 出現年代。未分類ならそのまま記載する |
| 状況 | プレイヤーが経験する出来事と、提示する情報 |
| 発生条件 | 年齢・状態・過去の選択など、発生に必要な条件 |
| 選択肢 | プレイヤーが選べる行動 |
| 結果 | 各選択の直後に起こること |
| 影響 | パラメータの変化と、後の人生への長期的な影響 |
| 分岐 | 条件や選択による展開、その後のイベントとの関係 |
| 学び | セキュリティイベントで扱うリスク・影響・対策 |
| 受け入れ条件 | 決定した内容と分岐を確認するための条件 |

金額を定める場合は円で記載します。選択肢の数、変化量、成功・失敗の扱い、再発や連続イベントの有無は、個別に決めるまで確定しません。

## 入力と出力

| 種類 | 概念上扱うもの |
| --- | --- |
| 入力 | 現在の年齢や状態、決定済みのイベント内容・条件、プレイヤーの選択 |
| 出力 | 提示する状況と選択肢、選択の結果、状態への影響、その後の分岐 |

## 受け入れ条件

- 採用し、詳細化したイベントについて、発生条件・選択肢・結果・影響・分岐を文書で確認できる。
- 決定した条件と選択に従って展開し、その結果と状態の変化が対応する。
- セキュリティに詳しくない人が、状況と選択の意味、リスク・影響・対策を生活の文脈で理解できるか検証する。
- 未採用の候補、未分類の年代、未決定の数値や分岐を、決定済みの仕様として扱わない。

## 候補と未採用案

既存の [SEC-001〜015](../events/security-events.md) はすべて採用未決定・年代未分類です。本文にある状況や結果も候補の内容であり、この共通仕様の作成によって採用したものではありません。候補の統合・分割も未決定です。

[制限時間による焦りの演出](../ideas/time-pressure.md) も未採用です。イベント共通の必須仕様や失敗条件には含めません。
