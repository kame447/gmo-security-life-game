# イベント共通仕様

イベントは日常生活の状況を提示し、プレイヤーが行動を選ぶことで、その結果と影響が生じる仕組みとする。マップ探索や自由行動からイベントにつなげ、選択の影響を [プレイヤーの状態](player-state.md) とその後の人生に反映する。

## イベントの種類

学校、進路、交友、仕事、恋愛、結婚などの日常イベントと、インターネットやデジタルサービス利用に伴うセキュリティイベントを組み合わせる。イベントの比率は日常対セキュリティでおおむね7:3〜6:4を目安とする。

セキュリティイベントは独立した知識クイズにせず、オンラインゲーム、SNSの写真投稿、ネット通販、フィッシングメール、Wi-Fi、アプリ権限、QR決済、宅配通知など、生活の中に発生させる。例示した題材は採用や配置年代の確定を意味しない。

選択の結果は所持金・交友関係・アカウント等の状態と後の分岐へ反映し、リスク、影響、対処方法を伝える。危険な判断から必ず被害が生じる設計を前提とせず、発生条件と結果は個別イベントで定義する。

## 個別イベントの管理

個別イベントには、題名、発生する状況、発生条件、選択肢、結果、プレイヤーの状態への影響、その後の分岐を記載する。金額は日本円で扱う。

具体的なイベント内容は [イベント文書](../events/README.md) にまとめる。生活上の目標との関係は [遊びの進行](gameplay.md) に記す。SEC-001〜015 は現時点で採用未決定・年代未分類であり、この進行方式の採用だけで個別イベントの採用は確定しない。
