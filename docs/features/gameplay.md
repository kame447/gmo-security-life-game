# 遊びの進行

状態：共通方針は合意済み。人生の進行速度や年代別の詳細は未決定。

## 目的と責務

プレイヤーがマップを探索し、自由に行動しながら人生を送れるようにします。生活の出来事とイベントでの選択をつなぎ、その場の結果と長期的な影響を経験できる流れを扱います。

## 合意済みの振る舞い

- 親しみやすい2Dドット絵のマップを探索し、自由に行動する。
- イベントに出会い、選択を通じて生活を進める。
- 学校、進路、交友、仕事、恋愛、転職、結婚、介護などの生活要素を主軸とする。
- 子ども〜学生〜成人〜中年〜高齢までを扱う。
- 選択が [プレイヤーの状態](player-state.md) と、その後の人生に影響する。

自由行動と人生の時間進行の関係は未決定です。探索中の時間経過、行動回数、ターン制などの方式は定めていません。生活要素をどの年代で、どの順番で経験するかも未決定です。

## 入力と出力

| 種類 | 概念上扱うもの |
| --- | --- |
| 入力 | プレイヤーの移動・行動・イベントでの選択、現在の年齢や状態、決定済みのマップ・行動・イベントの条件 |
| 出力 | 探索や生活の状況、発生するイベント、選択の結果、状態やその後の人生への影響 |

入力方法、移動のルール、具体的な画面、年代が移る契機は未決定です。

## 受け入れ条件

以下は機能を具体化・実装した際に確認する条件です。現時点で実装済みであることを示しません。

- マップ探索・自由行動とイベントでの選択が、一続きの人生シミュレーションとして遊べる。
- 日常の生活要素が体験の主軸となり、セキュリティイベントもその文脈で経験できる。
- 選択の結果と、後の人生への影響を確認できる。
- 全年代の完成時には、子どもから高齢までの生活を通じて遊べる。

## 未決定事項

- 人生の進行速度、時間の単位、年代の年齢範囲と移行条件。
- 年代別の生活内容、進路、人間関係、人生の分岐と終了条件。
- マップの種類・接続・移動条件、自由行動の具体的な選択肢。
- アイテムを欲しくなるきっかけと、入手・購入へつなげる導線。
- 操作方法と、状況・結果を伝える画面や演出。

全年代の生活イメージは [全体企画書](../product.md)、イベントの扱いは [イベント共通仕様](events.md) を参照してください。
