# 遊びの進行

プレイヤーは分割型2Dドット絵のマップを自由に探索し、人々との交流や生活上の行動を選びながら、幼少期から老後までの人生を送る。学校、交友、進路、仕事、恋愛、結婚、介護などの生活経験を中心に置く。

## 進行の単位

年代は生活上の主要タスクを達成することで人生の節目が解放され、プレイヤーがその節目を選択すると移行する。ルーレットや自動的な時計の進行を、年代移行の必須条件としない。自由移動・屋内外の出入り・場所の調査だけでは人生の時間を進めない。マップの構造や移動は [マップと探索](map.md) に記す。

## 目標タスク

「主要タスク」は年代を進めるために経験する生活上の目標である。序盤は複数の具体的なタスクを提示し、すべてを経験することで、その年代の次の節目を解放する。例として、幼少期の「公園へ行く」「友達と遊ぶ」「買い物を経験する」を想定できるが、実際のタスク一覧は未決定。

主要タスクの達成は必ずしも成功と同じではない。例えば友達と遊んだ結果、親しくなってもけんかしても、交流を経験したという進行上の達成とみなす。できなかった目的・失敗の影響は [プレイヤーの状態](player-state.md) に反映し、進行不能を避ける。

「任意タスク」は欲しい物を購入する、能力を伸ばす、友人関係を深めるなどの目標で、達成によって報酬や選択肢が増える。未達成でも次年代へ進める。場所の発見、会話、持ち物、生活状況をきっかけに追加のタスクが発生することも想定する。

序盤では行動を具体的に案内する。ゲームに慣れるにつれて「卒業後の進路を決める」「生活の基盤を作る」などの大きな目標に移り、達成方法の選択はプレイヤーに委ねる。後半のタスク件数・具体的条件は今後設計する。

## 人生の節目と引き継ぎ

その年代の主要タスクを達成すると、卒業や進路選択などの節目が解放される。節目の解放だけでは自動移行せず、プレイヤーが次年代への移行を選ぶ。移行時には所持金、能力、嗜好、持ち物、交友関係、過去の選択やイベント結果などを引き継ぐ。

節目解放後も町を探索し、任意タスクや生活行動を続けられる設計とする。ただし、同じ年代に留まり続けて同じ利益を無制限に得る問題への対策は未決定とする。

## 日常とセキュリティ

セキュリティ上の判断は、オンラインゲーム、SNS、通販、認証、通信、決済、仕事上の情報の扱いなど、通常の生活行動の途中に現れる。課題の目的はあくまで生活上の行為であり、正しいセキュリティ判断や被害回避を主要タスクの達成条件にはしない。

判断や出来事の影響をその場の結果と将来の分岐に反映する。過去の選択の影響は後の年代にも持ち越せる。イベントの具体的な発生条件、選択肢、結果は [イベント共通仕様](events.md) と [個別イベント候補](../events/README.md) で管理する。
