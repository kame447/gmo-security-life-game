# 自転車

主人公が自転車に乗って屋外を移動する試作。ローカル確認版では、母親へのお使いの報告後にスマホの Web で自転車を検索し、3店の内容を比べて購入する。入手前は乗れない。購入予算は仮に20,000円とし、店舗・価格・購入結果は [ローカル実装の買い物と通販](local-commerce.md) を参照する。[SEC-002](../events/security-events.md) を含む正式なイベント採用・配分は別途決定する。

## 操作と挙動

- 屋外では B キー、またはタッチ操作の「じてんしゃ」ボタンで乗り降りする。会話中は乗り降りできない。
- 乗っている間の速度は 176 px/秒、Shift を押している間は 240 px/秒に加速する（歩き 72、走り 128）。「徒歩のダッシュ ＜ 自転車 ＜ 自転車のダッシュ」の関係を保つ。数値は試作の提案値で、要検証。
- タッチでは、乗車中に表示する「加速 / 長押し」を押している間だけ 240 px/秒になる。方向ボタンとは別の指で押し、方向を変えても加速を保つ。指を離すと 176 px/秒へ戻り、次に押すまで加速しない。
- 会話・スマホなどの画面・地図・電車移動を開く、下車する、タッチ操作を隠す、画面を離れる操作でタッチ加速を解除する。`pointercancel` と `lostpointercapture` でも解除し、復帰時に押し直す。徒歩のタッチダッシュは今回追加しない。
- 当たり判定は歩くときと同じ。屋内に入ると自動で降り、屋内では乗れない。「さいしょから」でも降りる。
- 乗っている状態は保存しない。再読み込みすると降りた状態から始まる。
- 操作ヒントは、屋外で「B：じてんしゃ」、乗車中に「Shift：かそく　B：おりる」を表示する。

## 見た目

- `game/src/render/bicycle-sprite.ts` に 26×30 ドットで描く。頭・胴・配色は主人公のドット絵と共有し、外見の設定を反映する。
- 横向きは車輪のスポークとペダルが回る。正面・背面は車輪と泥よけを描く。正面は両手でハンドルを握り、背面には反射板を付ける。

## 未決定事項

- 自転車を所持品として扱うか、駐輪や乗り入れ禁止の場所。スマホでの購入はローカル確認版で実装し、価格と購入時のイベント内容は承認待ちとする。
- 年代ごとの車種（子ども用・大人用）と、乗っているときの当たり判定の大きさ。
- 徒歩のタッチダッシュ（[#15](https://github.com/kame447/gmo-security-life-game/issues/15)）。自転車のタッチ加速は [#66](https://github.com/kame447/gmo-security-life-game/issues/66) のローカル確認版として実装した。

## ローカルでの確認

`tests/ui-controller.test.ts` は方向と加速の同時保持、指の解放・中断、画面や移動手段の変更での解除を検査する。`scripts/e2e-bicycle-touch.mjs` は実際の複数タッチ入力で通常速度と加速速度、方向変更後の加速、解除、画面内のボタン配置を確認し、`SLG_SHOTS` を指定すると PC・縦向き・横向き・320px のスクリーンショットを保存する。`?review=1&skipOpening=1` を使うため通常の保存データには触れない。
