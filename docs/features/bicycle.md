# 自転車

主人公が自転車に乗って屋外を移動する試作。自転車の入手・購入（[SEC-002](../events/security-events.md) の題材案を含む）との連動は未決定。序章のお使いの後にスマホの通販で購入し（SEC-002 の偽通販サイトを題材にする）、入手前は乗れないようにする流れを [ストーリーの流れ](story.md) で提案中（未実装）。

## 操作と挙動

- 屋外では B キー、またはタッチ操作の「じてんしゃ」ボタンで乗り降りする。会話中は乗り降りできない。
- 乗っている間の速度は 176 px/秒、Shift を押している間は 240 px/秒に加速する（歩き 72、走り 128）。「徒歩のダッシュ ＜ 自転車 ＜ 自転車のダッシュ」の関係を保つ。数値は試作の提案値で、要検証。
- タッチでは、乗車中に移動の矢印を 300 ms 押し続けると 176 px/秒から 240 px/秒に加速する。方向を切り替えると通常速度に戻り、その方向を 300 ms 押し続けると再び加速する。すべての矢印から指を離すと加速を解除する。
- 会話やメニューの表示、降車、タッチ操作の非表示、画面の切り替えでも解除する。ブラウザがタッチを取り消すか、ポインターキャプチャが失われた場合も解除する。
- 当たり判定は歩くときと同じ。屋内に入ると自動で降り、屋内では乗れない。「さいしょから」でも降りる。
- 乗っている状態は保存しない。再読み込みすると降りた状態から始まる。
- 操作ヒントは、屋外で「B：じてんしゃ」、乗車中に「Shift：かそく　B：おりる」を表示する。

## 見た目

- `game/src/render/bicycle-sprite.ts` に 26×30 ドットで描く。頭・胴・配色は主人公のドット絵と共有し、外見の設定を反映する。
- 横向きは車輪のスポークとペダルが回る。正面・背面は車輪と泥よけを描く。正面は両手でハンドルを握り、背面には反射板を付ける。

## 未決定事項

- 自転車を所持品として扱うか、駐輪や乗り入れ禁止の場所。入手方法は [ストーリーの流れ](story.md) の提案（スマホで購入）が合意されれば確定する。
- 年代ごとの車種（子ども用・大人用）と、乗っているときの当たり判定の大きさ。
- 徒歩のタッチダッシュは [#15](https://github.com/kame447/gmo-security-life-game/issues/15) で扱う。

## ローカルでの確認

`game/` で `npm run dev -- --port 5511 --strictPort` を起動し、`node scripts/e2e-bicycle-touch.mjs` を実行する。タッチ時の速度・方向切り替え・キャプチャの解除と、PC の Shift 操作を検証する。`SLG_SHOTS` に保存先を指定すると画面を記録する。検証には通常のセーブデータから独立した `?review=1` を使う。
