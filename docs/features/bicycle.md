# 自転車

主人公が自転車に乗って屋外を移動する試作。自転車の入手・購入（[SEC-002](../events/security-events.md) の題材案を含む）との連動は未決定。

## 操作と挙動

- 屋外では B キー、またはタッチ操作の「じてんしゃ」ボタンで乗り降りする。会話中は乗り降りできない。
- 乗っている間の速度は 176 px/秒、Shift を押している間は 240 px/秒に加速する（歩き 72、走り 128）。「徒歩のダッシュ ＜ 自転車 ＜ 自転車のダッシュ」の関係を保つ。数値は試作の提案値で、要検証。
- 当たり判定は歩くときと同じ。屋内に入ると自動で降り、屋内では乗れない。「さいしょから」でも降りる。
- 乗っている状態は保存しない。再読み込みすると降りた状態から始まる。
- 操作ヒントは、屋外で「B：じてんしゃ」、乗車中に「Shift：かそく　B：おりる」を表示する。

## 見た目

- `game/src/render/bicycle-sprite.ts` に 26×30 ドットで描く。頭・胴・配色は主人公のドット絵と共有し、外見の設定を反映する。
- 横向きは車輪のスポークとペダルが回る。正面・背面は車輪と泥よけを描く。正面は両手でハンドルを握り、背面には反射板を付ける。

## 未決定事項

- 自転車を所持品として扱うか、入手方法、駐輪や乗り入れ禁止の場所。
- 年代ごとの車種（子ども用・大人用）と、乗っているときの当たり判定の大きさ。
- タッチ操作の加速ボタン（徒歩のダッシュも未対応）。スマホ操作メニューの整備時に、徒歩・自転車の両方を扱う（[#15](https://github.com/kame447/gmo-security-life-game/issues/15) に記録）。
