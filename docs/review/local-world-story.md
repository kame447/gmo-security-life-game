# 学校・職場・店内の交流を確認する

2026-11-28 のローカル実装。Issue #33 の客、Issue #86 の専用マップ、任意イベント、学校生活、漢字交じりの文面を対象とする。main や他担当者のリモートブランチは変更していない。場所・台詞・少量の得点はレビュー用の案。

## 画面で確認する内容

中学校では先生とクラスの友達に、高校では先生・クラスメイト・部活の友達に、大学ではゼミの先生・友達・サークルの友達に話しかける。授業の合間や節目の自由行動中に、勉強や交流の選択肢が出る。参加せずに必須の出来事だけ進めることもできる。「今回は見送る」を含め、選んだ出来事は再読み込み後も同じ年代で繰り返さない。

隣町の駅から北西へ行くと高校、さらに北西端に大学、川の手前の東側に会社がある。駅に着いただけでは、それぞれの必須の出来事は始まらない。目的地の屋内に入って初めて始まる。ミニマップは本町の駅入口から電車の乗り場、隣町の入口へ案内する。

全7店舗に客がいる。本屋の友達とは学生の時期におすすめの本を話し合え、喫茶店の友達とは中年・老後に近況を話せる。買い物は店員、普段の会話や任意の出来事は客という区別を保つ。

参加した任意イベントは人生の振り返りにも思い出として残る。`story.choices` を使用するため保存形式の追加はなく、以前の保存も読み込める。`stepsDone` と `stepElapsed` を進めたり消したりせず、卒業条件や必須イベントの順番にも加えない。

## 確認の根拠

scratch 上の Node 24 によるソース実行では、17エリアの `validateWorld` が問題0件、配置ファイルの生成元照合 `staleLayouts` が0件だった。任意12件をそれぞれ適切な年代で開始して選択し、必須イベントを進めず、再度の会話では再発しないことも確認した。

追加した回帰テストは `tests/story-optional.test.ts` と `tests/campus-world.test.ts`。年代・場所・序章の制限、参加と見送り、保存と再開、選ぶ前の中断、専用屋内での必須イベント開始、電車をまたぐ案内を確認する。既存の NPC 数やエリア数、文言の期待値は追加分へ更新した。

実ブラウザの確認・撮影は統合先で次を実行する。結果は統合側の記録に追記する。

```sh
SLG_URL=http://127.0.0.1:5500 SLG_SHOTS=/absolute/path/to/shots node scripts/e2e-local-world-story.mjs
```

このスクリプトは使い捨てのブラウザ保存を用意し、高校・大学・会社・喫茶店を 1280×800 と 390×844 で開く。実際の操作ボタンから任意イベントを選び、保存後の再読み込みと再発防止まで確認する。位置と年代だけを確認用に準備しており、普段の保存には触れない。撮影ファイルは `high-school-1280-room.png`・`high-school-390-choices.png` など、場所・幅・状態が分かる名前になる。
