# 通販とメール先Webの画面改修

2026-11-28 のユーザーレビューを反映したローカル修正。既存のページURL・注文ID・価格と購入処理を維持し、Webの見た目と閲覧内容を増やした。母からの3候補リンクはroot担当のメッセージ連携から開く。今回の変更には実際のWebへの遷移・決済・外部通信を含めない。

## 参考と作り方

cymaの公式サイト（https://cyclemarket.jp/）、イオンバイク公式サイト（https://www.aeonbike.jp/）、あさひ公式Yahoo!店の商品ページ（https://store.shopping.yahoo.co.jp/cyclemall/54960.html）を情報設計の参考にした。調査日は2026-11-28。商品画像、色、税込価格、仕様、整備・受取、支払い・返品、販売者の確認へ順に進む構成を参考にしている。実際のブランド・写真・ロゴ・商品コピーは複製していない。自転車はこの実装用のオリジナルSVG、図書館や商店街はCSSの図版で、素材の取得や外部配信は行わない。

## 変更内容

はやてサイクルは深緑、まちかどバイクはベージュ、CYCLE SELECTは紺とオレンジで、商品写真相当の自転車図版、商品名、価格、カラー見本、画像の拡大、仕様、販売者情報、利用ガイドを持つ。画像とカラーはその場で操作できる。カラーは写真の見本であり、注文として色が保存されるとは表示しない。商品・お届け・会社案内のナビはゲーム内の実ページへ移動し、端末の戻るボタンで履歴を戻る。

3店とも同程度の見た目で、正規・偽・危険・正解などを購入前に掲示しない。CYCLE SELECTの判断材料は、価格そのものではなく会社案内と利用ガイドで確認できる所在地の未掲載、個人名義口座、返信や納期の不明確さ、返品・返金の条件など。現時点の結果分岐や価格は既存の仮実装を維持している。

メール先の図書館にはブランド見出し、オリジナルの本の図版、催しの日時・会場・参加方法、初回参加の案内、館内ページを追加した。図書館の各ページを読んで端末で戻ると、元のメールに戻れる。商店街と天気の既存ページも固有のレイアウトへ整理し、これまで意図的に未作成だった商店街の案内ページを実ページへ置き換えた。

## 確認

`scripts/e2e-storefront-review.mjs` はPCと390px幅のタッチ画面で、母の3リンク、全候補の商品・色・画像、販売者・配送情報、注文の取消、予算超過の停止、母とのトークへの復帰、図書館メールから会場案内を経由して元メールへ戻る操作を確認する。通常保存の番兵データと外部リクエストも確認し、`SLG_SHOTS` 指定先へ各画面を撮る。

scratchで完了した検証は新しいTypeScriptモジュールの読込、全内部リンクの解決、自転車検索の3候補、商品から会社案内を経て戻る履歴、E2Eスクリプトの構文確認。Macの型検査・Vitest・実ブラウザは統合担当が実行して台帳へ記録する。
