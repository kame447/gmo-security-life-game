# 店内の人とイベント文章のレビュー修正

2026-11-28 の利用者レビューに対応したローカル案。既存 Issue #33 の店内の客と、既存のストーリーイベントを対象にしている。購入処理、商品の価格、イベントの選択 ID、得点、条件分岐は変えていない。

## 店内の人

喫茶店の読書中の客は窓際の椅子、友達はクリームソーダのある席に座る。椅子と同じタイルに配置し、向きをテーブルへそろえた。上体を下げ、膝を曲げた専用のドット絵にしている。読書中の客は手元に開いた本も描く。席が通れなくなる点は元の椅子と同じで、会話は隣の通路からできる。

専用ポーズは既存の sprite ID の追加として実装し、保存の形式や屋内の壁の描画には手を加えていない。配置エディタにも着席の 2 種を登録する。椅子の背が人物全体にかぶらないよう、使用している 2 脚だけを地面の後に描く。

残り 6 店の客は商品棚の隣に立ち、その棚を向く。コンビニは冷蔵ケース、八百屋は果物、本屋は平積み、駄菓子屋は箱棚、パン屋は焼きたての台、薬局は日用品の棚を見ている。入口、店員、商品への動線を残している。

## 判断する前に答えを表示しないイベント

自転車の比較を含む既存セキュリティイベント 33 件を見直した。導入では画面に実際にある情報、締切、相手との関係、使える連絡手段を示す。先に「怪しい」「不要な権限」などと評価したり、選択肢に「この先もずっと」のような未来の結果を書いたりしない。

選択肢は、予定を守る、友達と合流する、持ち主を探す、担当部署と確認するなど、その場で行う行動にそろえる。選んだ後の会話では、どの情報を使い、何を確認できていなかったかを説明する。「最長の文章」「常に下の選択肢」を選べば正答になる見せ方を減らすため、同じイベントでは順番を保ちながら、別のイベントでは位置が変わるようにしている。

言い換えで行動の範囲を曖昧にしないよう、別担当者のレビューも受けた。「メールのリンクを開く」だけで機密情報を入力したことにせず、入力する選択には項目を示す。更新日時を決めないこと、報告を調査後まで保留すること、取引の停止より照合を先にすることも選択前に分かるようにした。結果と振り返りが、選んでいない隠蔽や怠慢を勝手に加えないよう調整している。

口座や住宅ローンについては、この物語の人物の照会・資料確認が終わらず手続きや購入計画が保留になる経緯にした。現実の金融機関で一律に新規口座や住宅ローンが永久に利用できなくなるという教え方はしていない。被害額や返金額は従来の物語上の仮値であり、現実の補償条件や金額を示すものではない。

自転車の旧会話形式も、新しい通販ページの店名、商品、購入条件に合わせた。安さやメール窓口だけを結論にせず、所在地未掲載、個人名義口座への振込、返品・返金条件を合わせて確かめられる説明にしている。

任意イベント 12 件は元から日常の行動を選ぶ内容なので、ID や内容を増減していない。移動や待ち時間なしの直接確認は別のレビュー入口で行う。得点や金額の重みは従来の仮設定のままであり、今回の文面修正で正式採用を決めたものではない。
