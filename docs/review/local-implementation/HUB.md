# ローカル追加分の確認入口

2026-11-28の利用者レビューに合わせて、`http://127.0.0.1:5494/review.html` を今回追加・修正した箇所だけの入口に変更した。自転車通販は母のメッセージに届く3候補、メールは受信済みの図書館案内、全7店は購入画面を閉じた店内表示から確認する。買い物操作は仮合格として保持し、客の姿勢や配置を今回の確認点として示す。

保存・タイトル・クラウド、従来の自転車・電車デモ、既に統合したPRの画面は今回の一覧へ掲載しない。元の実装や確認用保存は削除していない。

## イベントを直接開く

追加した日常の任意イベント12件を、年代とイベント名で並べた。「導入から見る」を1回押すと、そのイベント専用の確認記録を始め直し、相手の最初の台詞から開始する。歩いて人物を探す操作や、時間の経過を待つ操作は要らない。選択肢だけを表示するのではなく、導入・選択・結果を通常のゲーム画面で確認できる。

既存セキュリティイベントの選択肢32件も、文章改善を確認する別の欄に並べている。これは新規イベントが32件増えたという意味ではない。年代で絞り、イベント名で検索できる。通販の導入は別のメッセージ入口を使うため、ここへ重複掲載していない。

一覧のデータは `game/src/app/local-event-review-catalog.ts` で既存のイベント定義から作る。URL は `?skipOpening=1&localReview=event-optional-univ-project` や `?skipOpening=1&localReview=event-univ-phishing` の形を使う。各場面の保存キーは `slg-map-save-v1.review.<場面ID>` で、通常の `slg-map-save-v1` は読まず、書き換えない。

画面上の確認帯には「一覧へ」「この場面をやり直す」「次の場面へ」がある。「やり直す」は当該場面の記録だけを復元ポイントへ退避して初期化する。選択後の単なる再読み込みでは選んだ内容を保持し、イベントを勝手に繰り返さない。別の選び方を試したいときは「やり直す」を押す。選択の正解や配点をこの確認帯へ表示しない。

## ゲームへの接続

従来どおり `opening/entry.ts` の `seedLocalReview` がタイトル読み込み前に空の確認用記録を準備する。対象はloopbackホストとカタログにある場面だけ。任意イベントは対応する人物の `eventKey` で `StoryDirector.onMapEvent` を呼び、通常の導入会話を開く。必須のセキュリティイベントは同じ年代の対象以外のステップを確認用に完了済みとし、対象の待ち時間だけ準備した状態から `StoryDirector.tick(0, true)` を1回呼ぶ。条件分岐のある場面にはその場面が発生するためのサンプル履歴を用意する。

`main.ts` では `story.attach` の後、ループ前に `installLocalEventReview(game, story)` を呼ぶ。返された `freezeProgress` がtrueの間は通常のフレームの `story.tick` を止め、別イベントや次の年代の導入が勝手に始まらないようにする。選択と結果、所持金への反映と記録は既存の処理を使う。通常プレイの条件や待ち時間は変更しない。

店内の入口は `shopScene=1` のときだけ購入画面の自動表示を止める。購入そのものは店員へ話しかければ通常どおり開始できる。

## 検証

scratchのNode 24実行では、44場面すべてについて、実在するエリアへの配置、最初の導入台詞、移動・時間待ちなしの開始、通常の選択記録を確認した。PCとスマホの実画面検証は統合先のMacで次を実行する。未実行の段階では成功と扱わない。

```sh
npx vitest run tests/local-event-review.test.ts tests/local-review-fixtures.test.ts --maxWorkers=1
SLG_URL=http://127.0.0.1:5494 SLG_SHOTS=/absolute/path/to/screens node scripts/e2e-local-review-hub.mjs
```

E2Eは1280×800と390×844で44場面の導入・選択・結果・保存分離を確認し、各選択画面を撮影する。加えて、検索、確認範囲の絞り込み、再読み込み、別の選択へのやり直し、次のイベント、一覧から1回のクリックで開く操作を確認する。`SLG_REVIEW_FILTER=optional` または `security` で対象を絞れる。
