# イベント文書

個別イベントの候補と詳細を管理する。

[セキュリティイベント候補](security-events.md) には、SEC-001〜SEC-015の15件を記録している。現在は検討段階で、出現する年代も未分類。SEC-002 のみ、序章（中学）の自転車購入で使う配置案が [ストーリーの流れ](../features/story.md) にある（合意待ち）。

[ステージごとの出来事の案](stage-event-proposals.md) は、[ストーリーの流れ](../features/story.md) の各ステージ（中学・高校・それ以降）で起こす出来事の叩き台で、チームに意見を募っている（未採用）。

個別イベントの詳細には、状況、発生条件、選択肢、結果、パラメータへの影響、後続の分岐を記載する。イベントに共通する仕組みは [イベント共通仕様](../features/events.md) を参照する。
