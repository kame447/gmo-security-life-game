# イベント文書

個別イベントの候補と詳細を管理する。

[セキュリティイベント候補](security-events.md) には、SEC-001〜SEC-015の15件を記録している。現在は検討段階で、出現する年代も未分類。ストーリーの試作（[ストーリーの流れ](../features/story.md)）では、利用者の指示（2026-11-28）で全件を仮に各ステージへ配置している。

[ストーリーの出来事一覧](story-events.md) には、試作のストーリーで起きる全出来事（ステージ・きっかけ・条件・状況・選択肢・結果・評価への影響・後の分岐）をまとめている。

個別イベントの詳細には、状況、発生条件、選択肢、結果、パラメータへの影響、後続の分岐を記載する。イベントに共通する仕組みは [イベント共通仕様](../features/events.md) を参照する。
