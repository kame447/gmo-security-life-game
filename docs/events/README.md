# イベント候補と詳細の管理

このディレクトリは、イベントの候補と、採用後に決まった個別イベントの詳細を管理する場所です。現在あるのは未採用の候補だけで、採用済みイベントの詳細仕様はまだありません。

## 現在の文書

- [セキュリティイベント案](security-events.md)：SEC-001〜015。全件が採用未決定・年代未分類。

IDは候補を継続して参照するためのもので、採用、優先度、実装順序を示しません。今後の検討や年代ごとの振り分けでも同じIDを使います。SEC-001〜015の統合・分割も未決定です。

日常イベントの具体案はまだ文書化していません。セキュリティの候補だけが置かれていることは、ゲーム内の配分を示すものではありません。生活を主軸とする方針と全年代のイメージは [全体企画書](../product.md) を参照してください。

## 個別イベントの詳細化

採用と詳細化を進める際は、[イベント共通仕様](../features/events.md) に沿って、発生条件、選択肢、結果、影響、分岐、受け入れ条件などを、決定した範囲で記載します。未決定の項目はその旨を明示します。

候補の本文に状況や結果が書かれていても、それだけで採用済みの仕様とは扱いません。特定の年代やパラメータへの割り当て、選択肢、変化量、後続イベントを推測して補いません。年代別の管理が必要になった時点で整理します。

ゲーム全体の演出や仕組みの未採用案は、個別イベントとは分けて [制限時間による演出案](../ideas/time-pressure.md) に記録します。
