# ストーリーの出来事一覧（試作）

状態：利用者の指示（2026-11-28）による試作の中身。採用・数値は未確定。進め方は [ストーリーの流れ](../features/story.md)、評価は Issue #62、SEC 候補は [セキュリティイベント案](security-events.md)。

> この文書は `game/src/story/config.ts`・`events.ts`・`score.ts` のデータから作った。中身を変えたら作り直す。

## 進め方の要点

- ステージはガントチャートに合わせて「中学生 → 高校生 → 大学生 → 社会人 → 中年・老後」。重点は高校・大学・社会人。
- 各ステージの出来事は上から順に一つずつ起きる。前の出来事を経験すると次が始まる。「条件」がある出来事は、満たさないと飛ばす。
- きっかけは「場所に入る」か「その場（前の出来事から探索中に一定秒数）」。学校・会社などからの知らせはスマホの受信トレイに届く。
- すべて経験すると、自室のベッドで次のステージへ進める。
- セキュリティの問題は、導入文（状況）に見抜くための手がかりを入れている。間違えた選択は、同じか後のステージで「被害の出来事」として返り、そこで対処するかを選ぶ。
- 評価（#62）：日常軸（お金・つながり・成長）とセキュリティ軸（判断・被害・対処）。満点の基準など仮値は `SCORE_TUNING`（つながり・成長 20、お金 3,000,000円）。最後に会話欄へ文言で出す（結果画面は未作成）。
