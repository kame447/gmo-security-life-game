# 画像素材の配置

このディレクトリはゲームで利用する画像の置き場所です。現在は主人公（男の子・女の子）の基本スプライトと年代差分のみ追加済みです。

## 役割ごとの配置先

### characters/：登場人物

- player/base/：主人公の基本スプライト・立ち絵
- player/age-variants/：成長・年代に応じた外見差分
- player/outfits/：衣装・外見カスタマイズの差分
- player/expressions/：表情差分
- player/animations/：歩行・方向転換などの動作素材
- player/portraits/：会話・プロフィール用の顔画像
- npcs/：NPCごとの素材。具体的なNPCが決まってから、そのIDを名前とするサブフォルダにスプライト・表情・顔画像をまとめる
- shared/：複数キャラクターで共有する素材

主人公の年代と服装の組合せ、NPCのIDや種類はまだ決めません。

### maps/：マップ画像

- locations/：場所ごとのマップ画像。具体的な場所が決まった時点で場所IDごとに分ける
- tilesets/terrain/：地面・道・水などの地形タイル
- tilesets/buildings/：建物外観用のタイル
- tilesets/interiors/：室内用のタイル
- backgrounds/：背景画像
- overlays/：前景・重ね合わせ画像
- previews/：マップの確認・選択用サムネイル

座標・当たり判定・イベント配置を含むマップデータの仕様と保存先は実装時に決めます。このディレクトリは画像素材用です。

### objects/：フィールド上の物

- props/：家具、装飾物、小道具
- interactables/：調べる・操作する対象物
- vehicles/：自転車などの乗り物

### ui/：インターフェース

- hud/：所持金・ステータスなどの常時表示
- menus/：メニュー画像
- dialogs/：会話枠・選択肢など
- buttons/：共通ボタン
- icons/：汎用アイコン
- indicators/：通知・状態表示・ガイドなど

### items/：所持品・アイテム

- icons/：持ち物一覧などの小画像
- illustrations/：拡大画像・詳細表示

### events/：イベント固有の画像

- security/：セキュリティイベント専用画像。必要になったら docs/events/security-events.md のSEC-001などのIDに合わせて下位フォルダを作る
- daily/：日常イベント専用画像
- cutscenes/：一枚絵・演出シーン

年代別の割当は未決定なので、現時点では年代別フォルダを固定しません。

### effects/：視覚演出

- particles/：エフェクト・粒子
- transitions/：画面遷移
- weather/：天候

### branding/：タイトル・広報素材

- logos/：ロゴ
- title/：タイトル画面固有素材
- promotional/：広報・公開ページ用画像

## AIエージェント向けルール

追加する画像は利用目的に合う場所へ一度だけ保存し、使い回す場合は同じ素材を参照します。NPC・場所・イベントは識別子が確定してから、そのIDを名前とするサブフォルダを作ります。ファイル名は英数字とハイフンを基本とします。

画像サイズ、スプライトシート構成、向きの数、アニメーションのフレーム数、描画技術、キャラクターの具体的な年代などは未決定です。フォルダ名から仕様が決まったと解釈しないでください。

編集可能な原本ファイルは assets/sources/images/ へ、ゲームで使用する書き出し画像はこのフォルダへ配置します。第三者の素材は公開・再配布可能な権利を確認し、出典とライセンスを追跡できるようにしてください。
