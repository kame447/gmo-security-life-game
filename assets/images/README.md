# 画像素材の配置

このディレクトリはゲームで利用する画像の置き場所です。現在は空フォルダのみで、画像素材はまだありません。

## 役割ごとの配置先

### characters/：登場人物

- player/base/：主人公の基本スプライト・立ち絵
- player/age-variants/：成長・年代に応じた外見差分
- player/outfits/：衣装・外見カスタマイズの差分
- player/expressions/：表情差分
- player/animations/：歩行・方向転換などの動作素材
- player/portraits/：会話・プロフィール用の顔画像
- npcs/：NPCごとの素材。具体的なNPCが決まってから、そのIDを名前とするサブフォルダにスプライト・表情・顔画像をまとめる
- shared/：複数キャラクターで共有する素材

主人公の年代と服装の組合せ、NPCのIDや種類はまだ決めません。

### maps/：マップ画像

- locations/：エリア（場所）IDごとの分割チャンク画像やロケーション画像（例：`locations/town-center/chunk-x000-y001.png`、`locations/home-family-interior/...`）。具体的なエリアIDが決まった時点でサブフォルダを分ける
- tilesets/terrain/：地面・道路・歩道・水路などの屋外地形タイル
- tilesets/buildings/：住宅・マンション・低中層ビル・店舗・学校などの建物外観タイル
- tilesets/interiors/：自宅・教室・店舗などの室内タイル
- backgrounds/：町の外へ続く幹線道路・線路・遠景などの背景画像
- overlays/：キャラクターの手前に重なる前景・遮蔽物（屋根・街路樹・標識など）や重ね合わせ画像
- previews/：各街区・屋内の「見た目の参考画像（リファレンス）」（例：`town-center-reference-v01.png`）や確認用サムネイル。参考画像は完成タイルや実ゲーム用チャンクとは区別し、ランタイムの描画データとして直接読み込まない

#### マップ素材の命名・分離ルール

- **エリア・施設ID**：永続・一意・意味を持つ英小文字 `kebab-case` とする（例：`town-center`、`town-residential-west`、`town-school-north`、`home-family-interior`）。画面上の日本語表示名とデータIDを混同しない。
- **チャンク識別子とファイル名**：チャンクはエリアIDと非負整数のグリッド座標で識別する（例：`town-center/chunk-x000-y001`、ファイル名 `chunk-x000-y001.png`）。見た目の並び替えだけでIDを変更しない。
- **版番号の扱い**：`-v01` などの版番号は、再生成や比較を行う参考画像（`previews/` 等）にのみ付与し、ランタイムが参照するIDや実ゲーム用の書き出しアセット名には埋め込まない。
- **用途別の分離**：屋外タイル、建物外観、室内タイル、前景／遮蔽物、装飾（`objects/props/`）、インタラクト対象（`objects/interactables/`）、背景を分離する。参考画像（`maps/previews/`）、編集可能な原本（`assets/sources/images/`）、ゲーム実行用の書き出し画像（`assets/images/`）を混在させない。
- **構造化データの分離**：座標・チャンク接続・当たり判定・出入口（ドアID）・インタラクション点・年代差分を含むマップ構造化データの保存先は、この画像ディレクトリとは別途定義する。詳細は [マップと探索](../../docs/features/map.md) を参照。

### objects/：フィールド上の物

- props/：家具、装飾物、小道具
- interactables/：調べる・操作する対象物
- vehicles/：自転車などの乗り物

### ui/：インターフェース

- hud/：所持金・ステータスなどの常時表示
- menus/：メニュー画像
- dialogs/：会話枠・選択肢など
- buttons/：共通ボタン
- icons/：汎用アイコン
- indicators/：通知・状態表示・ガイドなど

### items/：所持品・アイテム

- icons/：持ち物一覧などの小画像
- illustrations/：拡大画像・詳細表示

### events/：イベント固有の画像

- security/：セキュリティイベント専用画像。必要になったら docs/events/security-events.md のSEC-001などのIDに合わせて下位フォルダを作る
- daily/：日常イベント専用画像
- cutscenes/：一枚絵・演出シーン

年代別の割当は未決定なので、現時点では年代別フォルダを固定しません。

### effects/：視覚演出

- particles/：エフェクト・粒子
- transitions/：画面遷移
- weather/：天候

### branding/：タイトル・広報素材

- logos/：ロゴ
- title/：タイトル画面固有素材
- promotional/：広報・公開ページ用画像

## AIエージェント向けルール

追加する画像は利用目的に合う場所へ一度だけ保存し、使い回す場合は同じ素材を参照します。NPC・場所・イベントは識別子（英小文字 `kebab-case`、イベントは `SEC-001` 等の定義ID）が確定してから、そのIDを名前とするサブフォルダを作ります。ファイル名は英数字とハイフンを基本とし、参考画像（`-reference-v01` 等）と実ゲーム用素材を名前で識別できるようにします。

タイル寸法、1チャンクあたりのタイル数、スプライトシート構成、向きの数、アニメーションのフレーム数、具体的な描画ライブラリ、キャラクターの具体的な年代区分などは未決定（提案／要検証）です。フォルダ名から未決定の数値仕様が決まったと解釈しないでください。

編集可能な原本ファイルは `assets/sources/images/` へ、雰囲気検討用の参考画像は `assets/images/maps/previews/` へ、ゲームで使用する書き出し画像は対応する各フォルダへ配置します。生成・編集・書き出し素材の出典、使用ツール、ライセンス、再配布可否を記録し、第三者の作品をそのまま流用しないでください。
