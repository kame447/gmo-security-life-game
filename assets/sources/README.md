# 素材の編集元データ

画像の編集元ファイル（レイヤー保持データ、タイルアトラス編集元など）を保存するための場所です。

- ゲーム実行時に読み込む書き出し済み画像は [assets/images/](../images/README.md) に置きます。
- マップの雰囲気検討用に生成した参考画像（リファレンス）は `assets/images/maps/previews/` に置き、編集可能な原本やランタイム用画像と混在させません。

現在は空の配置先のみです。画像編集ツールや元データの形式は未決定です。

公開リポジトリに置く原本は、生成・作成元、使用条件、再配布権限、ファイルサイズを確認したものに限ります。第三者の著作物をそのまま流用したファイルは配置しません。
