# 素材置き場

ゲーム用素材を管理する場所です。現在はディレクトリだけを用意しており、素材ファイルはまだありません。

- [images/](images/)：主人公の差分、NPC、マップ、UI、アイテム、イベント、演出・ロゴなどの画像素材
- audio/：BGM、効果音など
- fonts/：フォント（配布が許可されているものに限る）
- [sources/](sources/)：画像などの編集元データ（公開できるものに限る）

素材の追加時は、出典・作者・ライセンス・必要なクレジット表記を確認し、第三者の権利を侵害するファイルを公開リポジトリに置かないでください。ライセンスを確認できない参考画像・音源はここへコミットしません。

画像の置き場所と分類方針は [images/README.md](images/README.md) を参照してください。画像形式や配信用ディレクトリ構成などの詳細は実装段階で決めます。
