# 素材置き場

ゲーム用素材を管理する場所です。現在はディレクトリだけを用意しており、素材ファイルはまだありません。

- [images/](images/)：主人公の差分、NPC、マップ、UI、アイテム、イベント、演出・ロゴなどの画像素材
- audio/：BGM、効果音など
- fonts/：フォント（配布が許可されているものに限る）
- [sources/](sources/)：画像などの編集元データ（公開できるものに限る）

素材の追加時は、生成・編集・書き出しの各段階について出典・作者・作成ツール・ライセンス・使用条件・再配布可否・必要なクレジット表記を確認し、第三者の権利を侵害するファイルを公開リポジトリに置かないでください。ライセンスを確認できない参考画像・音源はここへコミットしません。

画像の置き場所、参考画像・原本・書き出し画像の分離、およびマップ素材のID・命名規則は [images/README.md](images/README.md) と [マップと探索](../docs/features/map.md) を参照してください。圧縮方式、配信サイズ上限、マップ構造化データの配置先などの詳細は設計・実装段階で決めます。
